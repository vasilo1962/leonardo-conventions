# Leonardo Conventions

Ανεξάρτητο αποθετήριο της ενότητας https://leonardobridge.com/conventions.
Ανήκει στο έργο «Leonardo-επικοινωνία». Η εφαρμογή του παιχνιδιού δεν το εισάγει και δεν το ξαναχτίζει.

- Κοινός οδηγός: conventions_guide.md (ακριβές αντίγραφο έκδοσης 5 της 13/11/2026).
- Κείμενα: content/<σύμβαση>/<γλώσσα>.json. Κάθε αρχείο έχει δικό του slug και ρητή κατάσταση draft ή published.
- Κατάλογος: catalog.json. Γλώσσες: languages.json. Παλιοί σύνδεσμοι: redirects.json.
- Γραφικά: media/<σύμβαση>/, με προσβάσιμη περιγραφή στο άρθρο όταν προστεθεί η αντίστοιχη παρουσίαση.
- Το src/ είναι ανεξάρτητο στιγμιότυπο του υπάρχοντος δημόσιου περιβάλλοντος. Δεν συγχρονίζεται με το παιχνίδι.
- Δεν υπάρχουν προγράμματα παιχνιδιού, διανομές ή SQL migrations σε αυτό το αποθετήριο. Τα κοινά δημόσια χειριστήρια κρατούν το υπάρχον API και τις υπάρχουσες δημόσιες μεταβλητές Supabase.

Η αρχική μεταφορά διατηρεί τα υπάρχοντα 23 άρθρα και τις 26 μεταφράσεις τους. Δεν αποτελεί αναθεώρηση του εκπαιδευτικού περιεχομένου σύμφωνα με τον νέο οδηγό.

Ο οδηγός μεταφέρεται αυτούσιος: η παλιά ενότητα «Όρια και τεχνικές απαιτήσεις» καταγράφει την κατάσταση πριν από τη συμφωνία για ανεξάρτητη διαχείριση. Για τη νέα τεχνική λειτουργία ισχύουν το CONVENTIONS_PROJECT_RULES.md και το PUBLISHING.md αυτού του αποθετηρίου.

Η έκδοση προς προεπισκόπηση ταυτοποιείται από commit. Δημοσίευση μόνο μετά από το ρητό «πάμε» της Βάσως για εκείνη την έκδοση. Δεν μεταφέρονται κείμενα μέσω του έργου ανάπτυξης του παιχνιδιού.
