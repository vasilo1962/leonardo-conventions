Drury — ３番手・４番手のオープンに対するサポート

使い方、例とレスポンス

いつ使いますか？

自分がすでにパスし、パートナーが３番手または４番手で1♥か1♠をオープンしたときに使います。このレッスンではメジャー５枚以上を約束し、相手のオーバーコールはありません。インビテーションの強さと３枚以上のサポートでアーティフィシャルな2♣と答え、クラブは示しません。まずReverse Drury、次にサポート枚数を分けるTwo-way Druryを説明します。

何のためですか？

特に３番手ではライトオープンがあり得ます。インビテーションのジャンプレイズでは高くなり過ぎるかもしれません。Druryなら低いレベルで強さとフィットを示せます。オープナーはメジャーを２の代でリビッドしてプレーするか、適切な手ならゲームを探れます。

2♣は何を示しますか？

レスポンスレスポンス サポートサポート 強さと性質強さと性質
2♣ Drury2 クラブ Drury オープンしたメジャー３枚以上オープンしたメジャー３枚以上 ゲームへのインビテーション。アーティフィシャルで１巡フォーシングゲームへのインビテーション。アーティフィシャルで１巡フォーシング

通常のオープンに対してゲームを誘います。HCP、分布、フィットの質を合わせて評価し、先のパスが強さの上限を示します。**2♣はクラブを約束せず、オープナーはパスできません。**弱いサポートハンドなら２の代へシングルレイズ。サポート３枚未満ではDruryを使いません。

Druryのレスポンス例

自分はパス済み、パートナーが３番手か４番手でオープンし、相手はパスします。

1. ３枚サポート

オープンは1♠：

♠ K83スペード: キング, 8, 3.
♥ A74ハート: エース, 7, 4.
♦ Q962ダイヤモンド: クイーン, 9, 6, 2.
♣ Q85クラブ: クイーン, 8, 5.

2♣ Drury。11 HCP、３枚サポート。ゲームを誘いながら、ライトオープンに対して2♠で止まれます。

2. ４枚サポート

オープンは1♥：

♠ AQ84スペード: エース, クイーン, 8, 4.
♥ K963ハート: キング, 9, 6, 3.
♦ Q74ダイヤモンド: クイーン, 7, 4.
♣ 85クラブ: 8, 5.

2♣ Drury。11 HCP、４枚サポート、クラブのダブルトン。単純なReverse Druryはこの手も含み、３枚サポートに限定しません。

3. より弱い手

オープンは1♠：

♠ K83スペード: キング, 8, 3.
♥ Q74ハート: クイーン, 7, 4.
♦ J962ダイヤモンド: ジャック, 9, 6, 2.
♣ 853クラブ: 8, 5, 3.

2♠、シングルレイズ。フィットはありますが、6 HCPのバランスハンドではゲームを誘う強さが足りません。

どう続けますか？

以下は相手がずっとパスする前提です。

Reverse Druryでのオープナーのリビッド

**2♣**によりサポートとインビテーションの強さが分かります。このレッスンでは：

**メジャーの２の代はプレーするためで、レスポンダーはパスします。**ライトオープンでも、誘いに対して続けるほどでないミニマムでも可能です。**2♦**はレスポンダーの手を詳しく聞く余地を残し、それだけではゲームフォーシングではありません。両方の手を総合評価します。

1. 低く止まる

３番手で1♠をオープンし、レスポンスは2♣ Drury：

♠ KQ874スペード: キング, クイーン, 8, 7, 4.
♥ 83ハート: 8, 3.
♦ A62ダイヤモンド: エース, 6, 2.
♣ J95クラブ: ジャック, 9, 5.

2♠。10 HCPのライトオープンでゲームには進みたくありません。パートナーはパスします。

2. より詳しい説明を求める

３番手で1♠をオープンし、レスポンスは2♣ Drury：

♠ KQ874スペード: キング, クイーン, 8, 7, 4.
♥ A7ハート: エース, 7.
♦ K62ダイヤモンド: キング, 6, 2.
♣ J95クラブ: ジャック, 9, 5.

2♦。13 HCPの通常のオープンですが、ゲームはパートナーの手次第。この人工的なビッドはダイヤ３枚を示しません。本課の簡単な続け方では、Druryのミニマムはメジャーの２の代、マキシマムで適切な手はゲームへ進みます。４枚サポート、有用なショートスート、よいオナーは評価を上げます。点数だけでは決めません。より詳しい取り決めもあります。

3. ゲームをビッド

３番手で1♠をオープンし、レスポンスは2♣ Drury：

♠ AQJ84スペード: エース, クイーン, ジャック, 8, 4.
♥ K7ハート: キング, 7.
♦ A62ダイヤモンド: エース, 6, 2.
♣ Q95クラブ: クイーン, 9, 5.

4♠。16 HCP、よい５枚メジャー、パートナーの誘いを合わせれば十分です。先に2♦を経由する必要はありません。

Bergen Raisesとの関係

３番手・４番手のオープンにもBergen Raisesを使うペアがあります。４枚以上のサポートを持つ誘いをBergenで示すなら、2♣ Reverse Druryをちょうど３枚サポート専用にでき、Two-wayは不要です。これは別の取り決め。本課の単純なDruryは３枚以上を示します。

Two-way Drury

単純なDruryでは合計８枚フィットか、それ以上かが分かりません。この違いがゲーム判断に影響します。Two-wayでは：

レスポンスレスポンス 意味意味
2♣2 クラブ インビテーション、ちょうど３枚サポートインビテーション、ちょうど３枚サポート
2♦2 ダイヤ インビテーション、４枚以上のサポートインビテーション、４枚以上のサポート

両方ともアーティフィシャルで１巡フォーシング。ビッドしたマイナーの長さは示しません。パス済みであること、パートナーが３番手・４番手で1♥/1♠をオープンすることは変わりません。

Two-wayでのリビッド

  • メジャーの２の代はプレーするため。レスポンダーはパス。
  • メジャーの４の代は誘いを受けます。

2♣の後は2♦の問いかけが使えます。レスポンスが2♦なら４枚以上のサポートが分かり、この問いかけは使えません。他のインビテーションの続け方は別途合意が必要です。代償として、自然な2♣レスポンスに加え、自然な2♦レスポンスも失います。

Two-wayの例 — ちょうど３枚サポート

自分はパス済み、パートナーが３番手・４番手で1♠をオープンし、相手はパス：

♠ KQ7スペード: キング, クイーン, 7.
♥ A84ハート: エース, 8, 4.
♦ Q962ダイヤモンド: クイーン, 9, 6, 2.
♣ 853クラブ: 8, 5, 3.

2♣ Drury。11 HCP、トランプちょうど３枚。誘いと正確なサポート枚数を示します。

Two-wayの例 — ４枚サポート

同じ状況でオープンは1♠：

♠ KQ74スペード: キング, クイーン, 7, 4.
♥ A83ハート: エース, 8, 3.
♦ Q962ダイヤモンド: クイーン, 9, 6, 2.
♣ 85クラブ: 8, 5.

2♦ Drury。同じ11 HCPですが、４枚サポートとクラブのダブルトンがあります。オープンが５枚を約束するので、オープナーは直ちに９枚以上のフィットを知ります。単純なDruryなら両手とも2♣、Two-wayでは**2♣と2♦**で区別します。

注意点

  • 先のパスが必須。相手ではなく、パートナーの３番手・４番手1♥/1♠に答えます。
  • ３枚以上のサポートが必要。よい手でもフィットなしでは使えません。
  • 本課では相手のダブルやオーバーコール後はDruryを使わず、他の取り決めに従います。
  • メジャーの２の代はプレーするため。誘いは示したのでパスします。
  • 版を合意します。単純な2♣は３枚以上、Two-wayは2♣がちょうど３枚、2♦が４枚以上。
  • この位置でのBergen、特にDrury併用は別途合意が必要です。
