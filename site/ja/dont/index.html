ブリッジを学ぶ

DONT

使い方、例とレスポンス

いつ使う？

相手の強い1NTの直後にも、２回パスが続いた４番手のバランシングでも使います。

目的は？

通常２の代にとどまりながら１スーターや２スーターを示し、自分たちのコントラクトを探して相手のビディングを妨げます。ダブルはペナルティではなく１スーターです。

各コールの意味は？

1NTへのコール 意味
ダブル まだスート不明の１スーター
2♣ クラブとそれより高いスート：ダイヤモンド、ハートまたはスペード
2♦ ダイヤモンドとメジャー
2♥ ハートとスペード
2♠ ナチュラルなスペード

２スーターは最低5–4で、低い方が５枚である必要はありません。１スーターの例は６枚以上です。

分布とスートの質があれば少ないハイカードポイントでも使えます。２の代にとどまれるので積極的に介入でき、特にバランシングで有効です。バルネラビリティも判断に入れます。

例

すべて右の相手が強い1NTでオープン。

1. ハートの１スーター

♠ 83スペード: 8, 3.
♥ KQJ974ハート: キング, クイーン, ジャック, 9, 7, 4.
♦ A62ダイヤモンド: エース, 6, 2.
♣ 75クラブ: 7, 5.

ダブル。パートナーが2♣、相手がパスなら**2♥**へ。直接2♥なら両メジャーを示します。

2. クラブとスペード

♠ KJ84スペード: キング, ジャック, 8, 4.
♥ 6ハート: 6.
♦ 972ダイヤモンド: 9, 7, 2.
♣ AQ965クラブ: エース, クイーン, 9, 6, 5.

2♣。2♦で２つ目のスートを尋ねられたら2♠。

3. ダイヤモンドとスペード

♠ KJ84スペード: キング, ジャック, 8, 4.
♥ 6ハート: 6.
♦ AQ975ダイヤモンド: エース, クイーン, 9, 7, 5.
♣ 862クラブ: 8, 6, 2.

2♦。2♥でメジャーを尋ねられたら**2♠**に直します。

4. 両メジャー

♠ KJ84スペード: キング, ジャック, 8, 4.
♥ AQ975ハート: エース, クイーン, 9, 7, 5.
♦ 6ダイヤモンド: 6.
♣ 862クラブ: 8, 6, 2.

2♥、両メジャー最低5–4。パートナーはパスかスペードを選択。

5. スペードの１スーター

♠ QJ9864スペード: クイーン, ジャック, 9, 8, 6, 4.
♥ 7ハート: 7.
♦ K82ダイヤモンド: キング, 8, 2.
♣ 963クラブ: 9, 6, 3.

ナチュラルな2♠。この版では直接の2♠はダブル後の2♠より弱い手です。

パートナーのレスポンスは？

以下は相手がパスする場合です。

ダブルの後

通常**2♣**でスートを尋ねます。

ダブルした側の続き スート
パス クラブ
2♦ ダイヤモンド
2♥ ハート
2♠ スペード

2♣はクラブを約束しません。ペナルティだと考えてダブルを残さないでください。

2♣または2♦の後

既知のスートが適切ならパス。それ以外は次のスートをpass or correctとしてビッドし、そこが第２スートならパス、そうでなければ訂正してもらいます。**2♣の後の2♦**は第２スート、**2♦の後の2♥**はメジャーへの質問です。

2♥の後

ハートを選ぶならパス、スペードなら2♠。

レスポンス例：既知のスートにとどまる

左の相手1NT、パートナー2♣、右の相手パス：

♠ Q742スペード: クイーン, 7, 4, 2.
♥ 83ハート: 8, 3.
♦ K962ダイヤモンド: キング, 9, 6, 2.
♣ J75クラブ: ジャック, 7, 5.

クラブ３枚サポートでパス。第２スートがハートなら自分には２枚しかありません。

レスポンス例：メジャーを探す

同じ状況でパートナーは2♦：

♠ Q864スペード: クイーン, 8, 6, 4.
♥ K975ハート: キング, 9, 7, 5.
♦ 6ダイヤモンド: 6.
♣ J842クラブ: ジャック, 8, 4, 2.

2♥、pass or correct。両メジャーをサポートでき、パートナーはハートならパス、スペードなら2♠です。

注意点

  • 2♥は２スーターで、ハートの１スーターではありません。
  • 第２スートは必ず第１スートより高いランクです。
  • 第２スートを探しても、より良いフィットになる保証はありません。
  • パートナーの2NTはゲームへの関心を示す質問で、続きの合意が必要。単純な第２スート探しではありません。
