Multi Landy

使い方、例とレスポンス

いつ使う？

相手のナチュラルな1NTオープンに対するディフェンスです。強い1NT、弱い1NT、または両方に使うかを事前に決めます。ここではダブルはペナルティ、2♦は任意の１スートの長い手で、マイナーも含みます。

目的は？

１スーターや２スーターを示し、パートナーが切札を選びやすくするとともに、相手のビディングを妨げます。多くのオーバーコールは人工的で、実際にそのスートを持つとは限りません。

各オーバーコールの意味は？

コールコール 意味意味
ダブルダブル ペナルティ。1NTを落とせると判断ペナルティ。1NTを落とせると判断
2♣2 クラブ 両メジャー、少なくとも5–4両メジャー、少なくとも5–4
2♦2 ダイヤ 任意の６枚以上の１スート。通常はメジャー任意の６枚以上の１スート。通常はメジャー
2♥2 ハート ハート５枚とマイナー。マイナーは通常５枚だが、良い４枚でも可ハート５枚とマイナー。マイナーは通常５枚だが、良い４枚でも可
2♠2 スペード スペード５枚とマイナー。マイナーは通常５枚だが、良い４枚でも可スペード５枚とマイナー。マイナーは通常５枚だが、良い４枚でも可
2NT2 ノートランプ 両マイナー、少なくとも5–5両マイナー、少なくとも5–5
3♣ / 3♦3 クラブ / 3 ダイヤ そのマイナーのナチュラルなオーバーコールそのマイナーのナチュラルなオーバーコール

判断には分布、スートの質、バルネラビリティ、相手の1NTの強さを考慮します。ペナルティ・ダブルには守備のトリックと適切なオープニングリードが必要で、点数だけでは決めません。

オーバーコールの例

以下は右の相手が1NTでオープン。分布を示すオーバーコールでは自分たちはノンバルとします。

1. 両メジャー

♠ KQ96スペード: キング, クイーン, 9, 6.
♥ AJ853ハート: エース, ジャック, 8, 5, 3.
♦ 7ダイヤモンド: 7.
♣ Q62クラブ: クイーン, 6, 2.

2♣。ハート５枚、スペード４枚を示し、選択をパートナーに任せます。

2. 長い１スート

♠ AQJ964スペード: エース, クイーン, ジャック, 9, 6, 4.
♥ 852ハート: 8, 5, 2.
♦ K72ダイヤモンド: キング, 7, 2.
♣ 7クラブ: 7.

**2♦**で１スーターを示します。2♠ではありません。2♠はマイナーも約束するからです。

3. ハートとマイナー

♠ 7スペード: 7.
♥ KQJ86ハート: キング, クイーン, ジャック, 8, 6.
♦ AQ974ダイヤモンド: エース, クイーン, 9, 7, 4.
♣ 82クラブ: 8, 2.

2♥。ハート５枚とマイナーを示します。どちらのマイナーかはまだ不明です。

4. スペードとマイナー

♠ KJ853スペード: キング, ジャック, 8, 5, 3.
♥ 6ハート: 6.
♦ 84ダイヤモンド: 8, 4.
♣ AQ974クラブ: エース, クイーン, 9, 7, 4.

2♠。スペード５枚とマイナー。この手ではクラブです。

5. 両マイナー

♠ 7スペード: 7.
♥ 84ハート: 8, 4.
♦ KQJ96ダイヤモンド: キング, クイーン, ジャック, 9, 6.
♣ AJ874クラブ: エース, ジャック, 8, 7, 4.

2NTでクラブとダイヤモンドを各５枚以上示します。人工的なビッドで、バランスハンドではありません。

6. ペナルティ・ダブル

♠ AQJスペード: エース, クイーン, ジャック.
♥ KQ4ハート: キング, クイーン, 4.
♦ KJ93ダイヤモンド: キング, ジャック, 9, 3.
♣ K82クラブ: キング, 8, 2.

例えば12–14点の弱い1NTにダブル。守備力のある強い手なので、1NTダブルを守りたいのであり、スート選択を求めていません。

どうレスポンスする？

次の相手がパスした場合です。

2♣の後

最適なメジャーフィットを探します。

レスポンスレスポンス 意味意味
2♥ / 2♠2 ハート / 2 スペード そのメジャーへの選好。ゲームへのインビテーションではないそのメジャーへの選好。ゲームへのインビテーションではない
2♦2 ダイヤ 両メジャー同じ枚数。長い方を尋ねる両メジャー同じ枚数。長い方を尋ねる
3♥ / 3♠3 ハート / 3 スペード ４枚以上のサポート、ゲームへのインビテーション４枚以上のサポート、ゲームへのインビテーション

選好がある例

♠ A842スペード: エース, 8, 4, 2.
♥ 97ハート: 9, 7.
♦ J843ダイヤモンド: ジャック, 8, 4, 3.
♣ 975クラブ: 9, 7, 5.

2♠。スペード４枚、ハート２枚。パートナーに最低４枚あるので計８枚以上です。最初のオーバーコール例の手ならパートナーはパスし、自分の５枚ハートへ直しません。

選好がない例

♠ 852スペード: 8, 5, 2.
♥ Q96ハート: クイーン, 9, 6.
♦ A843ダイヤモンド: エース, 8, 4, 3.
♣ 974クラブ: 9, 7, 4.

両メジャー３枚ずつで2♦。最初の例の手ならパートナーは2♥。スペード７枚でなくハート８枚のフィットを見つけます。

2♦の後

長いスートは未確定。通常は**2♥をpass or correct（そのスートならパス、それ以外なら訂正）**として使います。

  • ハートならパス。
  • スペードなら2♠。
  • クラブなら3♣。
  • ダイヤモンドなら3♦。

例：２番目のオーバーコールの手。

西西 北北 東東 南南
1NT1 ノートランプ 2♦2 ダイヤ パスパス 2♥2 ハート
パスパス 2♠2 スペード

南の2♥はハートを示さず、北の長いスートを明らかにします。**2♠**で答えることもできますが、パートナーがハートなら少なくとも3♥でプレーする用意が必要です。これはナチュラルなスペードではありません。2NTの質問など強いレスポンスには、その後の追加の取り決めが必要です。

2♥または2♠の後

メジャーは既知、マイナーは不明です。

レスポンスレスポンス 意味意味
パスパス 既知のメジャーでプレー既知のメジャーでプレー
2NT2 ノートランプ マイナーを尋ねる。答えは3♣または3♦マイナーを尋ねる。答えは3クラブまたは3ダイヤ
別のスート別のスート ナチュラル。通常良い６枚以上、そのスートでプレーナチュラル。通常良い６枚以上、そのスートでプレー
パートナーのメジャーを３にレイズパートナーのメジャーを３にレイズ この版ではゲームへのインビテーションこの版ではゲームへのインビテーション

パートナーが３番目の手で2♥。ハートを避けたければ2NTで尋ね、**3♦**を聞きます。ここで2NTはノートランプでのプレーを提案しません。

2NTの後

両マイナー最低5–5です。弱い手ならサポートに従って**3♣か3♦**を選び、点が少ないからと人工的な2NTをパスしません。強い手ではフィット、トリック、ストッパーを考えてゲームを検討します。

ペナルティ・ダブルの後

通常はパスして守ります。非常に弱く自分に５枚以上のスートがあれば、ナチュラルな逃げのビッドも可能です。単に弱いという理由だけで４枚スートに逃げません。

注意点

  • **2♣**は両メジャー。
  • **2♦**は長い１スート。
  • **2♥と2♠**はマイナーも約束。
  • 2NTのオーバーコールは両マイナー。2♥や2♠へのレスポンスならマイナーへの質問。
  • 版によって違います。ダブル、2♦にマイナーを含むか、レイズがインビテーションかプリエンプトかを合意します。
