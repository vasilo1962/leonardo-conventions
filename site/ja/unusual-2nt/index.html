Unusual 2NT2 ノートランプ

使い方、例とレスポンス

いつ使う？

右の相手の１の代のスートオープンに、ジャンプして2NT2 ノートランプをオーバーコールします。

目的は？

まだビッドされていない低い方の２スートを、各５枚以上示します。同時に２スートを伝え、パートナーの選択を助けます。人工的で、バランスハンドでも、ノートランプの提案でもありません。

各ビッドの意味は？

オープンオープン オーバーコールオーバーコール 意味意味
1♣1 クラブ 2NT2 ノートランプ ダイヤモンドとハート各５枚以上ダイヤモンドとハート各５枚以上
1♦1 ダイヤ 2NT2 ノートランプ クラブとハート各５枚以上クラブとハート各５枚以上
1♥1 ハート 2NT2 ノートランプ クラブとダイヤモンド各５枚以上クラブとダイヤモンド各５枚以上
1♠1 スペード 2NT2 ノートランプ クラブとダイヤモンド各５枚以上クラブとダイヤモンド各５枚以上

必ず両マイナーという意味ではなく、両マイナーになるのはメジャーオープンに対してです。Michaelsと同様、この版は弱い手か非常に強い手で使い、中間ならナチュラルなオーバーコールから。分布があれば強さを問わないペアもあります。

例

1. 1♣1 クラブの後

右の相手が1♣1 クラブでオープン：

♠ 6スペード: 6.
♥ KJ975ハート: キング, ジャック, 9, 7, 5.
♦ QJ864ダイヤモンド: クイーン, ジャック, 8, 6, 4.
♣ 62クラブ: 6, 2.

2NT2 ノートランプ。未ビッドの低い２スート、ダイヤモンドとハートが各５枚以上。

2. 1♦1 ダイヤの後

右の相手が1♦1 ダイヤでオープン：

♠ 84スペード: 8, 4.
♥ AQ975ハート: エース, クイーン, 9, 7, 5.
♦ 6ダイヤモンド: 6.
♣ KJ963クラブ: キング, ジャック, 9, 6, 3.

2NT2 ノートランプ。クラブとハートが各５枚以上。ダイヤモンドは相手が既にビッドしています。

3. メジャーオープンの後

右の相手が1♠1 スペードでオープン：

♠ 6スペード: 6.
♥ 84ハート: 8, 4.
♦ KJ975ダイヤモンド: キング, ジャック, 9, 7, 5.
♣ QJ864クラブ: クイーン, ジャック, 8, 6, 4.

2NT2 ノートランプ、両マイナー各５枚以上。**1♥1 ハート**に対しても同じビッドです。

パートナーのレスポンスは？

次の相手がパスなら示された２スートから選びます。弱い手では最も低い代で選好を示し、点数や確実なフィットを約束しません。通常は長い方、同じ枚数ならスートの質とビッドの代を考慮します。

1. マイナーの選択

左の相手1♠1 スペード、パートナー2NT2 ノートランプ、右の相手パス：

♠ 842スペード: 8, 4, 2.
♥ K763ハート: キング, 7, 6, 3.
♦ Q85ダイヤモンド: クイーン, 8, 5.
♣ 972クラブ: 9, 7, 2.

3♦3 ダイヤ。両マイナー３枚ですが、ダイヤモンドのQはクラブの小さいカードより役立つかもしれません。

2. ハートかダイヤモンドか

左の相手1♣1 クラブ、パートナー2NT2 ノートランプ、右の相手パス：

♠ 8742スペード: 8, 7, 4, 2.
♥ Q963ハート: クイーン, 9, 6, 3.
♦ 85ダイヤモンド: 8, 5.
♣ K72クラブ: キング, 7, 2.

3♥3 ハート。示されたのはダイヤモンドとハートで、ハートには４枚サポートがあります。

注意点

  • 常に両マイナーではありません。オープンにより異なります。
  • 最低5–5。この版では5–4や6–4では使いません。
  • スートの質とバルネラビリティを考慮。通常レスポンスは３の代です。
  • 弱い手は単純な選好に通常パス。非常に強い手は続けて強さを示します。

Unusual 2NT2 ノートランプは通常Michaels Cue Bidと組み合わせます。異なるスートの組み合わせを示します。
