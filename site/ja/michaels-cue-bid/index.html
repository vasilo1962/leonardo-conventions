ブリッジを学ぶ

Michaels Cue Bid

使い方、例とレスポンス

いつ使う？

右の相手が１の代でスートをオープンしたとき、同じスートを２の代でキュービッドし、２スーターを示します。人工的で、相手のスートの長さを示しません。この版では両方のスートに５枚以上必要です。

目的は？

２つの長いスートを一度に示し、パートナーに切札を選んでもらいます。マイナーオープンには両メジャー、メジャーオープンにはもう一方のメジャーと未確定のマイナーを示します。

各ビッドの意味は？

相手のオープン相手のオープン キュービッドキュービッド 意味意味
1♣1 クラブ 2♣2 クラブ ハートとスペード各５枚以上ハートとスペード各５枚以上
1♦1 ダイヤ 2♦2 ダイヤ ハートとスペード各５枚以上ハートとスペード各５枚以上
1♥1 ハート 2♥2 ハート スペード５枚以上、マイナー５枚以上スペード５枚以上、マイナー５枚以上
1♠1 スペード 2♠2 スペード ハート５枚以上、マイナー５枚以上ハート５枚以上、マイナー５枚以上

弱い手か非常に強い手で使います。中間の強さならナチュラルなオーバーコールから。弱い手はパートナーの単純な選好に通常パスし、非常に強い手は続けて強さを示します。強さを問わず使うペアもありますが、ここでは中間の手はナチュラルです。

次の相手がパスすればパートナーは必ずレスポンスします。弱い手は最も安い選好にパスできます。

例

1. 両メジャー

右の相手が1♦でオープン：

♠ KJ864スペード: キング, ジャック, 8, 6, 4.
♥ QJ975ハート: クイーン, ジャック, 9, 7, 5.
♦ 8ダイヤモンド: 8.
♣ 62クラブ: 6, 2.

2♦、両メジャー各５枚以上。パートナーが低い代でメジャーを選び、相手がパスなら自分もパスします。

2. もう一方のメジャーとマイナー

右の相手が1♥でオープン：

♠ AQ975スペード: エース, クイーン, 9, 7, 5.
♥ 6ハート: 6.
♦ 84ダイヤモンド: 8, 4.
♣ KJ963クラブ: キング, ジャック, 9, 6, 3.

2♥、スペード５枚以上とマイナー５枚以上。パートナーはスペードを選ぶか2NTでマイナーを尋ねます。質問には**3♣**と答えます。

3. 非常に強い手

右の相手が1♣でオープン：

♠ AKJ84スペード: エース, キング, ジャック, 8, 4.
♥ AQ975ハート: エース, クイーン, 9, 7, 5.
♦ 6ダイヤモンド: 6.
♣ K2クラブ: キング, 2.

**2♣で両メジャー。パートナーが2♥を選んだら3♥**へ進み、非常に強い手を示します。少し助けになるカードがあればパートナーはゲームをビッドします。

その後の進め方は？

次の相手がパスした場合です。

両メジャーを示した場合

自分に長いメジャーを選びます。最も安い選好は点数を約束せず、０点でも可能です。同じ枚数なら通常ハートを選び、低く保ちます。

メジャーと未知のマイナーを示した場合

既知のメジャーを選ぶか、2NTでマイナーを尋ねます。

2NTへの答え2NTへの答え 意味意味
3♣3 クラブ クラブクラブ
3♦3 ダイヤ ダイヤモンドダイヤモンド

2NTは人工的な質問で、ナチュラルなノートランプへのインビテーションではありません。それ自体で強さを保証しません。どちらのマイナーでもプレーする用意が必要です。

レスポンス例１：メジャーの選好

左の相手1♦、パートナー2♦ Michaels、右の相手パス：

♠ J83スペード: ジャック, 8, 3.
♥ 9642ハート: 9, 6, 4, 2.
♦ A7ダイヤモンド: エース, 7.
♣ 8654クラブ: 8, 6, 5, 4.

2♥。パートナーは各メジャー最低５枚。自分はハート４枚、スペード３枚なのでハートを選びます。

レスポンス例２：マイナーを探す

左の相手1♥、パートナー2♥ Michaels、右の相手パス：

♠ 7スペード: 7.
♥ Q862ハート: クイーン, 8, 6, 2.
♦ J975ダイヤモンド: ジャック, 9, 7, 5.
♣ K864クラブ: キング, 8, 6, 4.

2NT。スペードは１枚、両マイナーに４枚サポートがあります。**3♣か3♦**と答えたらパス。

注意点

  • 5–5以上が必要。マイナーオープンに両メジャー5–4を許すペアもありますが、ここでは採用しません。
  • 弱い手か非常に強い手で使用。中間ならナチュラルに始めます。すべての強さで使う版もあります。
  • 分布だけでなくスートの質とバルネラビリティを検討。特にレスポンスが３の代になる場合です。
  • 最も安い選好は点数も確実なフィットも約束しません。弱い手で既に示した分布を繰り返すために続けません。

Michaelsは通常Unusual 2NTと組み合わせます。示すスートの組み合わせが異なります。
