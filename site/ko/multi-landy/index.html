브리지 배우기

Multi Landy

사용법, 예시와 응답

언제 사용하나요?

상대의 내추럴 1NT 오프닝에 대한 방어입니다. 강한 1NT, 약한 1NT 또는 둘 다에 사용할지 먼저 합의합니다. 여기서는 더블은 페널티이고, 2♦는 네 수트 중 어느 것이든 긴 한 수트를 뜻합니다.

목적은 무엇인가요?

한 수트 또는 두 수트를 알려 파트너가 트럼프를 선택하게 하며 상대의 비딩을 방해합니다. 대부분 인위적인 오버콜이므로 부른 수트를 실제로 갖고 있다는 뜻은 아닙니다.

분포, 수트의 질, 벌너러빌리티와 상대 1NT의 강도를 고려합니다. 페널티 더블에는 방어 트릭과 적절한 첫 리드가 필요하며 점수만 세어 결정하지 않습니다.

오버콜 예시

모두 오른쪽 상대가 1NT로 오픈했습니다. 분포를 이용하는 오버콜에서는 우리 편이 논벌너러블이라고 가정합니다.

1. 양 메이저

♠ KQ96스페이드: 킹, 퀸, 9, 6.
♥ AJ853하트: 에이스, 잭, 8, 5, 3.
♦ 7다이아몬드: 7.
♣ Q62클럽: 퀸, 6, 2.

2♣: 하트 5장, 스페이드 4장. 파트너가 선택합니다.

2. 긴 한 수트

♠ AQJ964스페이드: 에이스, 퀸, 잭, 9, 6, 4.
♥ 852하트: 8, 5, 2.
♦ K72다이아몬드: 킹, 7, 2.
♣ 7클럽: 7.

**2♦**로 한 수트를 표시합니다. 2♠는 마이너도 약속하므로 사용하지 않습니다.

3. 하트와 마이너

♠ 7스페이드: 7.
♥ KQJ86하트: 킹, 퀸, 잭, 8, 6.
♦ AQ974다이아몬드: 에이스, 퀸, 9, 7, 4.
♣ 82클럽: 8, 2.

2♥: 하트 5장과 마이너. 어떤 마이너인지는 아직 모릅니다.

4. 스페이드와 마이너

♠ KJ853스페이드: 킹, 잭, 8, 5, 3.
♥ 6하트: 6.
♦ 84다이아몬드: 8, 4.
♣ AQ974클럽: 에이스, 퀸, 9, 7, 4.

2♠: 스페이드 5장과 마이너이며 여기서는 클럽입니다.

5. 양 마이너

♠ 7스페이드: 7.
♥ 84하트: 8, 4.
♦ KQJ96다이아몬드: 킹, 퀸, 잭, 9, 6.
♣ AJ874클럽: 에이스, 잭, 8, 7, 4.

2NT: 클럽과 다이아몬드 각각 최소 5장. 균형 잡힌 핸드를 뜻하지 않는 인위적인 비드입니다.

6. 페널티 더블

♠ AQJ스페이드: 에이스, 퀸, 잭.
♥ KQ4하트: 킹, 퀸, 4.
♦ KJ93다이아몬드: 킹, 잭, 9, 3.
♣ K82클럽: 킹, 8, 2.

예를 들어 12–14점의 약한 1NT에 더블합니다. 방어력이 있는 강한 핸드로, 파트너에게 수트를 고르라는 뜻이 아니라 더블된 1NT를 방어하려는 것입니다.

어떻게 응답하나요?

다음 상대가 패스한 경우입니다.

2♣ 이후

가장 좋은 메이저 핏을 찾습니다.

응답응답 의미의미
2♥ / 2♠2 하트 / 2 스페이드 해당 메이저 선호, 게임 초청 아님해당 메이저 선호, 게임 초청 아님
2♦2 다이아몬드 양 메이저 길이가 같으므로 더 긴 쪽을 질문양 메이저 길이가 같으므로 더 긴 쪽을 질문
3♥ / 3♠3 하트 / 3 스페이드 4장 이상 지원, 게임 초청4장 이상 지원, 게임 초청

선호가 있는 예

♠ A842스페이드: 에이스, 8, 4, 2.
♥ 97하트: 9, 7.
♦ J843다이아몬드: 잭, 8, 4, 3.
♣ 975클럽: 9, 7, 5.

2♠. 스페이드 4장에 하트 2장입니다. 파트너가 스페이드 최소 4장이므로 합계 최소 8장입니다. 첫 오버콜 예시의 핸드라면 파트너는 패스하며 자신의 5장 하트로 고치지 않습니다.

선호가 없는 예

♠ 852스페이드: 8, 5, 2.
♥ Q96하트: 퀸, 9, 6.
♦ A843다이아몬드: 에이스, 8, 4, 3.
♣ 974클럽: 9, 7, 4.

양 메이저가 3장씩이므로 2♦. 첫 예시의 핸드를 가진 파트너는 **2♥**를 불러 스페이드 7장 대신 하트 8장 핏을 찾습니다.

2♦ 이후

긴 수트를 아직 모르므로 보통 **2♥**로 pass or correct를 요청합니다. 하트면 패스하고, 아니면 실제 긴 수트로 고치라는 뜻입니다.

  • 하트면 패스.
  • 스페이드면 2♠.
  • 클럽이면 3♣.
  • 다이아몬드면 3♦.

예시: 두 번째 오버콜 핸드입니다.

서서 북북 동동 남남
1NT1 노트럼프 2♦2 다이아몬드 패스패스 2♥2 하트
패스패스 2♠2 스페이드

남의 2♥는 하트를 보여 주지 않고 북의 긴 수트를 묻습니다. 2♠ 응답도 가능하지만 파트너가 하트일 때 최소 3♥를 감수해야 하며 내추럴 스페이드가 아닙니다. 2NT 질문 같은 강한 응답에는 이후 진행을 따로 합의해야 합니다.

2♥ 또는 2♠ 이후

메이저는 알지만 마이너는 모릅니다.

패스패스 알려진 메이저에서 플레이알려진 메이저에서 플레이
2NT2 노트럼프 마이너 질문: 3♣ 또는 3♦마이너 질문: 3 클럽 또는 3 다이아몬드

파트너 메이저를 3으로 레이즈파트너 메이저를 3으로 레이즈 여기서는 게임 초청여기서는 게임 초청

세 번째 핸드로 파트너가 **2♥**를 오버콜했습니다. 하트를 원하지 않으면 2NT로 물어 **3♦**를 듣습니다. 여기서 2NT는 노트럼프 제안이 아닙니다.

2NT 이후

파트너는 양 마이너 최소 5–5입니다. 약한 핸드는 지원에 따라 **3♣ 또는 3♦**를 선택하며, 점수가 적다는 이유로 인위적인 2NT에 패스하지 않습니다. 강한 핸드는 핏, 트릭, 스토퍼를 살펴 게임을 고려합니다.

페널티 더블 이후

보통 패스하여 방어합니다. 매우 약하면서 자기 수트가 5장 이상이면 내추럴하게 탈출할 수 있습니다. 점수가 적다고 자동으로 4장 수트로 도망가지 않습니다.

기억할 점

  • **2♣**는 양 메이저입니다.
  • **2♦**는 긴 한 수트입니다.
  • **2♥와 2♠**는 마이너도 약속합니다.
  • 2NT 오버콜은 양 마이너, 2♥ 또는 2♠에 대한 응답이면 마이너 질문입니다.
  • 버전이 다양합니다. 더블, 2♦의 마이너 포함 여부, 초청성 또는 방해성 레이즈를 합의해야 합니다.
