Michaels Cue Bid

用法、实例与应叫

什么时候使用？

右手敌方开叫一阶花色，我们在二阶扣叫同一花色，表示双套牌。这是约定叫，不表示敌方花色的长度。本版本要求两套各至少五张。

有什么作用？

一次说明两个长套，让同伴选将牌。对低花开叫表示双高花；对高花开叫表示另一高花加一门尚未确定的低花。

各叫品表示什么？

1♣1 梅花 2♣2 梅花 至少五张红心、五张黑桃至少五张红心、五张黑桃
1♦1 方块 2♦2 方块 至少五张红心、五张黑桃至少五张红心、五张黑桃
1♥1 红桃 2♥2 红桃 至少五张黑桃及一门至少五张的低花至少五张黑桃及一门至少五张的低花

本课用弱牌或很强的牌。中等实力先自然争叫。弱牌通常在同伴简单选择后不叫；很强的牌继续叫牌表示额外实力。有些搭档不限制实力，但不是这里采用的方法。

若下一位敌方不叫，同伴必须回应约定性扣叫。弱牌可以在同伴最便宜的选择后不叫。

实例

1. 双高花

右手敌方开叫1♦：右手敌方开叫1方块：

♠ KJ864黑桃: K, J, 8, 6, 4.
♥ QJ975红心: Q, J, 9, 7, 5.
♦ 8方块: 8.
♣ 62梅花: 6, 2.

叫2♦，两门高花至少各五张。同伴在低阶选择高花、敌方不叫时，我们也不叫。叫2方块，两门高花至少各五张。同伴在低阶选择高花、敌方不叫时，我们也不叫。

2. 另一高花加低花

右手敌方开叫1♥：右手敌方开叫1红桃：

♠ AQ975黑桃: A, Q, 9, 7, 5.
♥ 6红心: 6.
♦ 84方块: 8, 4.
♣ KJ963梅花: K, J, 9, 6, 3.

叫2♥，至少五张黑桃加五张低花。同伴可选择黑桃，或用2NT询问低花，我们回答3♣。叫2红桃，至少五张黑桃加五张低花。同伴可选择黑桃，或用2NT询问低花，我们回答3梅花。

3. 很强的牌

右手敌方开叫1♣：右手敌方开叫1梅花：

♠ AKJ84黑桃: A, K, J, 8, 4.
♥ AQ975红心: A, Q, 9, 7, 5.
♦ 6方块: 6.
♣ K2梅花: K, 2.

叫2♣，表示双高花。同伴选择2♥后，我们继续3♥，表示很强的牌。同伴稍有帮助就会叫到成局。叫2梅花，表示双高花。同伴选择2红桃后，我们继续3红桃，表示很强的牌。同伴稍有帮助就会叫到成局。

怎样继续？

以下假设下一位敌方不叫。

已表示双高花时

选择自己较长的高花。最便宜的选择不保证点力，甚至可能零点。等长时通常选择红心，以保持较低阶数。

已表示高花加未知低花时

可选择已知高花，或叫2NT询问低花：

对2NT的回答对2NT的回答 含义含义
3♣3 梅花 低花是梅花低花是梅花
3♦3 方块 低花是方块低花是方块

2NT是约定性询问，不是邀打无将，也不自动保证强牌。询问前应准备好在任一低花中打牌。

应叫例1：选择高花

左手敌方开叫1♦，同伴扣叫2♦ Michaels，右手敌方不叫：左手敌方开叫1方块，同伴扣叫2方块 Michaels，右手敌方不叫：

♠ J83黑桃: J, 8, 3.
♥ 9642红心: 9, 6, 4, 2.
♦ A7方块: A, 7.
♣ 8654梅花: 8, 6, 5, 4.

叫2♥。同伴双高花各至少五张，我们四张红心比三张黑桃更适合支持。叫2红桃。同伴双高花各至少五张，我们四张红心比三张黑桃更适合支持。

应叫例2：寻找低花

左手敌方开叫1♥，同伴扣叫2♥ Michaels，右手敌方不叫：左手敌方开叫1红桃，同伴扣叫2红桃 Michaels，右手敌方不叫：

♠ 7黑桃: 7.
♥ Q862红心: Q, 8, 6, 2.
♦ J975方块: J, 9, 7, 5.
♣ K864梅花: K, 8, 6, 4.

叫2NT。只有一张黑桃，但双低花各四张。回答**3♣或3♦**后不叫。叫2NT。只有一张黑桃，但双低花各四张。回答**3梅花或3方块**后不叫。

要点

  • 必须5–5。有些搭档对低花开叫接受双高花5–4，本课不采用。
  • 弱牌或很强牌用Michaels，中等实力先自然争叫。有些搭档接受任意实力。
  • 还要考虑套质和局况，尤其同伴须到三阶应叫时。
  • 最低阶选择不保证点力或确定的配合。弱牌不要只为重复已经说明的牌型而继续叫牌。

Michaels通常与Unusual 2NT配合使用，两者表示不同花色组合。
