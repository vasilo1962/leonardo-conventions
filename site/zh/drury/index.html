Reverse Drury

用法、实例与应叫

何时使用？

我们已经不叫，随后同伴在第三或第四家开叫1♥或1♠。本课约定开叫至少五张高花，对方不争叫。持邀局实力、对同伴高花至少三张支持时，应叫人为的2♣，不表示草花。我们已经不叫，随后同伴在第三或第四家开叫1红桃或1黑桃。本课约定开叫至少五张高花，对方不争叫。持邀局实力、对同伴高花至少三张支持时，应叫人为的2梅花，不表示草花。

有什么作用？

尤其在第三家，同伴可能轻开叫。如果直接跳加叫邀局，可能叫得过高。Drury能在低阶说明实力和配合：开叫人可以再叫二阶原高花，表示要打此定约；手牌合适时也可探索成局。

Drury应叫示例

以下均为我们已经不叫，同伴在第三或第四家开叫，对方不叫。

1. 三张支持

同伴开叫1♠：同伴开叫1黑桃：

♠ K83黑桃: K, 8, 3.
♥ A74红心: A, 7, 4.
♦ Q962方块: Q, 9, 6, 2.
♣ Q85梅花: Q, 8, 5.

叫2♣ Drury。11大牌点、三张支持，邀局同时保留面对轻开叫停在2♠的余地。叫2梅花 Drury。11大牌点、三张支持，邀局同时保留面对轻开叫停在2黑桃的余地。

2. 四张支持

同伴开叫1♥：同伴开叫1红桃：

♠ AQ84黑桃: A, Q, 8, 4.
♥ K963红心: K, 9, 6, 3.
♦ Q74方块: Q, 7, 4.
♣ 85梅花: 8, 5.

叫2♣ Drury。11大牌点、四张支持、草花双张。普通Reverse Drury也包括这手牌，不限于三张支持。叫2梅花 Drury。11大牌点、四张支持、草花双张。普通Reverse Drury也包括这手牌，不限于三张支持。

3. 较弱的手牌

同伴开叫1♠：同伴开叫1黑桃：

♠ K83黑桃: K, 8, 3.
♥ Q74红心: Q, 7, 4.
♦ J962方块: J, 9, 6, 2.
♣ 853梅花: 8, 5, 3.

叫2♠，简单加叫。虽然有配合，但6大牌点、均型，不足以邀局。叫2黑桃，简单加叫。虽然有配合，但6大牌点、均型，不足以邀局。

与Bergen Raises的关系

有些搭档在第三或第四家开叫后也采用Bergen Raises。如果Bergen已经表示至少四张支持的邀局牌，就可以把2♣ Reverse Drury保留为恰好三张支持，不需要Two-way。这是独立的搭档约定；本课普通Drury仍表示至少三张支持。。如果Bergen已经表示至少四张支持的邀局牌，就可以把2梅花 Reverse Drury保留为恰好三张支持，不需要Two-way。这是独立的搭档约定；本课普通Drury仍表示至少三张支持。

注意事项

  • 必须此前已经不叫，面对同伴第三或第四家1♥/1♠开叫。
  • 至少三张支持；牌好但无配合仍不能用。
  • 本课在对方加倍或争叫后不使用Drury，按其他搭档约定处理。
  • 二阶原高花表示要打此定约；已经说明邀局实力，应不叫。
  • Reverse Drury用2♣表示至少三张支持。Two-way Drury用2♣表示恰好三张、2♦表示至少四张，两者都是邀局实力。
  • Bergen用于这些位置需另行约定，与Drury合用时尤其如此。
