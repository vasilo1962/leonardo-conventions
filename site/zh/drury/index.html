Drury — 第三或第四家开叫后的加叫

用法、实例与应叫

何时使用？

我们已经不叫，随后同伴在第三或第四家开叫1♥或1♠。本课约定开叫至少五张高花，对方不争叫。持邀局实力、对同伴高花至少三张支持时，应叫人为的2♣，不表示草花。先介绍不区分支持长度的Reverse Drury，再介绍区分三张和更长支持的Two-way Drury。

有什么作用？

尤其在第三家，同伴可能轻开叫。如果直接跳加叫邀局，可能叫得过高。Drury能在低阶说明实力和配合：开叫人可以再叫二阶原高花，表示要打此定约；手牌合适时也可探索成局。

2♣表示什么？

应叫应叫 支持支持 实力及性质实力及性质
2♣ Drury2 梅花 Drury 对开叫高花至少三张支持对开叫高花至少三张支持 邀局实力；人为叫，逼叫一轮邀局实力；人为叫，逼叫一轮

这是面对正常开叫的邀局。综合评估大牌点、牌型和配合质量；此前的不叫限制了我们的实力。**2♣不保证草花，开叫人不能不叫。**较弱但有配合时，直接简单加叫到二阶。没有三张支持，不使用Drury。

Drury应叫示例

以下均为我们已经不叫，同伴在第三或第四家开叫，对方不叫。

1. 三张支持

同伴开叫1♠：

♠ K83黑桃: K, 8, 3.
♥ A74红心: A, 7, 4.
♦ Q962方块: Q, 9, 6, 2.
♣ Q85梅花: Q, 8, 5.

叫2♣ Drury。11大牌点、三张支持，邀局同时保留面对轻开叫停在2♠的余地。

2. 四张支持

同伴开叫1♥：

♠ AQ84黑桃: A, Q, 8, 4.
♥ K963红心: K, 9, 6, 3.
♦ Q74方块: Q, 7, 4.
♣ 85梅花: 8, 5.

叫2♣ Drury。11大牌点、四张支持、草花双张。普通Reverse Drury也包括这手牌，不限于三张支持。

3. 较弱的手牌

同伴开叫1♠：

♠ K83黑桃: K, 8, 3.
♥ Q74红心: Q, 7, 4.
♦ J962方块: J, 9, 6, 2.
♣ 853梅花: 8, 5, 3.

叫2♠，简单加叫。虽然有配合，但6大牌点、均型，不足以邀局。

如何继续？

以下叫牌过程中，对方始终不叫。

Reverse Drury中开叫人的再叫

应叫**2♣**后，开叫人知道同伴有配合和邀局实力。本课约定：

再叫再叫 含义含义
二阶原高花二阶原高花 要打此定约，无成局兴趣要打此定约，无成局兴趣
2♦2 方块 人为叫：正常开叫、有成局兴趣但尚未决定；不保证方块，逼叫一轮人为叫：正常开叫、有成局兴趣但尚未决定；不保证方块，逼叫一轮
四阶原高花四阶原高花 接受邀请，叫到成局接受邀请，叫到成局

**再叫二阶原高花表示要打，答叫人不叫。**既可以是轻开叫，也可以是面对邀局仍不足以继续的低限。**2♦**留出空间了解答叫人的手牌，本身不逼叫成局；应综合评估双方的牌。

1. 停在低阶

我们在第三家开叫1♠，同伴应叫2♣ Drury：

♠ KQ874黑桃: K, Q, 8, 7, 4.
♥ 83红心: 8, 3.
♦ A62方块: A, 6, 2.
♣ J95梅花: J, 9, 5.

叫2♠。10大牌点的轻开叫，无意继续探索成局。同伴不叫。

2. 询问更多信息

我们在第三家开叫1♠，同伴应叫2♣ Drury：

♠ KQ874黑桃: K, Q, 8, 7, 4.
♥ A7红心: A, 7.
♦ K62方块: K, 6, 2.
♣ J95梅花: J, 9, 5.

叫2♦。13大牌点，正常开叫，但是否成局取决于同伴。此人为叫不表示我们的三张方块。本课采用简单后续：答叫人持Drury低限叫二阶高花，持高限且牌质合适叫成局。四张支持、有用的短门和好的大牌可提高估值，不能只数点。这是本课约定，也有更详细的叫法。

3. 叫成局

我们在第三家开叫1♠，同伴应叫2♣ Drury：

♠ AQJ84黑桃: A, Q, J, 8, 4.
♥ K7红心: K, 7.
♦ A62方块: A, 6, 2.
♣ Q95梅花: Q, 9, 5.

叫4♠。16大牌点、好的五张高花，加上同伴邀局支持，足以接受。无须先叫2♦。

与Bergen Raises的关系

有些搭档在第三或第四家开叫后也采用Bergen Raises。如果Bergen已经表示至少四张支持的邀局牌，就可以把2♣ Reverse Drury保留为恰好三张支持，不需要Two-way。这是独立的搭档约定；本课普通Drury仍表示至少三张支持。

Two-way Drury

普通Drury不区分双方共有八张将牌还是更多，这可能影响成局判断。Two-way区分：

应叫应叫 含义含义
2♣2 梅花 邀局实力，恰好三张支持邀局实力，恰好三张支持
2♦2 方块 邀局实力，至少四张支持邀局实力，至少四张支持

两种叫牌都是人为叫、逼叫一轮，不表示所叫低花的长度。仍须我们此前不叫，同伴第三或第四家开叫1♥或1♠。

Two-way中开叫人的再叫

  • 二阶原高花表示要打，答叫人不叫。
  • 四阶原高花接受邀局。

应叫2♣后，开叫人的2♦询问仍可使用。应叫2♦后，开叫人已知至少四张支持，不能再用该询问；其他邀局后续需要另行约定。代价是除了失去自然的2♣应叫，还失去自然的2♦应叫。

Two-way示例 — 恰好三张支持

我们此前不叫，同伴第三或第四家开叫1♠，对方不叫：

♠ KQ7黑桃: K, Q, 7.
♥ A84红心: A, 8, 4.
♦ Q962方块: Q, 9, 6, 2.
♣ 853梅花: 8, 5, 3.

叫2♣ Drury。11大牌点、恰好三张将牌，表示邀局并明确支持长度。

Two-way示例 — 四张支持

同样的叫牌背景，开叫1♠：

♠ KQ74黑桃: K, Q, 7, 4.
♥ A83红心: A, 8, 3.
♦ Q962方块: Q, 9, 6, 2.
♣ 85梅花: 8, 5.

叫2♦ Drury。同样11大牌点，但有四张支持和草花双张。开叫保证五张高花，所以开叫人立即知道至少九张配合。普通Drury两手牌都应叫2♣；Two-way用**2♣和2♦**区分。

注意事项

  • 必须此前已经不叫，面对同伴第三或第四家1♥/1♠开叫。
  • 至少三张支持；牌好但无配合仍不能用。
  • 本课在对方加倍或争叫后不使用Drury，按其他搭档约定处理。
  • 二阶原高花表示要打此定约；已经说明邀局实力，应不叫。
  • 确认版本：普通2♣三张以上；Two-way 2♣恰好三张，2♦至少四张。
  • Bergen用于这些位置需另行约定，与Drury合用时尤其如此。
