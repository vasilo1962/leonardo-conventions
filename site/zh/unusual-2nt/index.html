学习桥牌

Unusual 2NT

用法、实例与应叫

什么时候使用？

右手敌方开叫一阶花色，我们跳争叫2NT。

有什么作用？

表示尚未叫过的两门最低级别花色，至少5–5，帮助同伴选择定约。这是约定叫，不表示平均牌型，也不建议打无将。

各叫品表示什么？

敌方开叫 我方争叫 所示花色
1♣ 2NT 至少五张方块、五张红心
1♦ 2NT 至少五张梅花、五张红心
1♥ 2NT 至少五张梅花、五张方块
1♠ 2NT 至少五张梅花、五张方块

所以并非总是双低花，只有对高花开叫才如此。与Michaels一样，本课用弱牌或很强的牌；中等实力先自然争叫。有些搭档牌型合适即可使用，不限实力。

实例

1. 对1♣开叫

右手敌方开叫1♣：

♠ 6黑桃: 6.
♥ KJ975红心: K, J, 9, 7, 5.
♦ QJ864方块: Q, J, 8, 6, 4.
♣ 62梅花: 6, 2.

叫2NT，至少五张方块、五张红心：未叫花色中最低的两门。

2. 对1♦开叫

右手敌方开叫1♦：

♠ 84黑桃: 8, 4.
♥ AQ975红心: A, Q, 9, 7, 5.
♦ 6方块: 6.
♣ KJ963梅花: K, J, 9, 6, 3.

叫2NT，至少五张梅花、五张红心。方块已由敌方叫过。

3. 对高花开叫

右手敌方开叫1♠：

♠ 6黑桃: 6.
♥ 84红心: 8, 4.
♦ KJ975方块: K, J, 9, 7, 5.
♣ QJ864梅花: Q, J, 8, 6, 4.

叫2NT，至少五张梅花、五张方块。若开叫是1♥，也作相同争叫。

同伴怎样应叫？

下一位敌方不叫时，从所示两门花色中选一门。弱牌在最低阶选择。简单选择不保证点力或确定的配合。通常选较长花色；等长时考虑套质和叫牌阶数。

1. 在双低花中选择

左手敌方开叫1♠，同伴争叫2NT，右手敌方不叫：

♠ 842黑桃: 8, 4, 2.
♥ K763红心: K, 7, 6, 3.
♦ Q85方块: Q, 8, 5.
♣ 972梅花: 9, 7, 2.

叫3♦。双低花各三张，但方块Q可能比梅花小牌更有用。

2. 在红心与方块中选择

左手敌方开叫1♣，同伴争叫2NT，右手敌方不叫：

♠ 8742黑桃: 8, 7, 4, 2.
♥ Q963红心: Q, 9, 6, 3.
♦ 85方块: 8, 5.
♣ K72梅花: K, 7, 2.

叫3♥。同伴表示方块和红心，我们有四张红心支持。

要点

  • 不一定是双低花，具体取决于敌方开叫。
  • 至少5–5；5–4或6–4不符合本版本。
  • 考虑套质和局况，同伴通常须在三阶应叫。
  • 弱牌通常在简单选择后不叫；很强牌继续叫出额外实力。

Unusual 2NT通常与Michaels Cue Bid配合使用，两者表示不同花色组合。
