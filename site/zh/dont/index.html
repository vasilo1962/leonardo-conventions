DONT

用法、实例与应叫

什么时候使用？

对抗敌方强1NT1 无将，既可直接争叫，也可在随后两家不叫后的第四家位置使用。

有什么作用？

表示单套或双套牌，通常保持在二阶，寻找本方定约并干扰敌方叫牌。加倍不是惩罚性，而是表示单套牌。

各叫品表示什么？

对1NT的叫品对1 无将的叫品 含义含义
加倍加倍 一门尚未确定的长套一门尚未确定的长套
2♣2 梅花 梅花加更高级别花色：方块、红心或黑桃梅花加更高级别花色：方块、红心或黑桃
2♦2 方块 方块加一门高花方块加一门高花
2♥2 红桃 红心和黑桃红心和黑桃
2♠2 黑桃 自然黑桃叫自然黑桃叫

双套至少5–4，较低级别的花色不一定是五张。单套例手采用六张或更长套。

牌型和套质合适时，大牌点较少也可使用DONT。通常能留在二阶，因此可更积极，尤其在第四家平衡位置。仍须考虑局况。

实例

以下右手敌方均开叫强1NT1 无将。

1. 红心单套

♠ 83黑桃: 8, 3.
♥ KQJ974红心: K, Q, J, 9, 7, 4.
♦ A62方块: A, 6, 2.
♣ 75梅花: 7, 5.

先加倍。同伴应叫2♣2 梅花、敌方不叫后，叫2♥2 红桃。直接争叫2♥2 红桃会表示双高花。

2. 梅花和黑桃

♠ KJ84黑桃: K, J, 8, 4.
♥ 6红心: 6.
♦ 972方块: 9, 7, 2.
♣ AQ965梅花: A, Q, 9, 6, 5.

叫2♣2 梅花。同伴用2♦2 方块问第二套时，答2♠2 黑桃。

3. 方块和黑桃

♠ KJ84黑桃: K, J, 8, 4.
♥ 6红心: 6.
♦ AQ975方块: A, Q, 9, 7, 5.
♣ 862梅花: 8, 6, 2.

叫2♦2 方块，方块加高花。同伴用2♥2 红桃问高花时，改叫2♠2 黑桃。

4. 双高花

♠ KJ84黑桃: K, J, 8, 4.
♥ AQ975红心: A, Q, 9, 7, 5.
♦ 6方块: 6.
♣ 862梅花: 8, 6, 2.

叫2♥2 红桃，双高花至少5–4。同伴可不叫或选择黑桃。

5. 黑桃单套

♠ QJ9864黑桃: Q, J, 9, 8, 6, 4.
♥ 7红心: 7.
♦ K82方块: K, 8, 2.
♣ 963梅花: 9, 6, 3.

自然争叫2♠2 黑桃。本版本中，直接2♠2 黑桃比先加倍再叫2♠2 黑桃更弱。

同伴怎样应叫？

以下假设敌方均不叫。

加倍后

通常叫2♣2 梅花，让同伴说明长套：

加倍者的后续加倍者的后续 花色花色
不叫不叫 梅花梅花
2♦2 方块 方块方块
2♥2 红桃 红心红心
2♠2 黑桃 黑桃黑桃

应叫2♣2 梅花不保证梅花。不要把加倍当作惩罚性而保留。

2♣2 梅花或2♦2 方块后

已知花色合适可以不叫，否则叫下一门花色作pass or correct（不叫或改正）：同伴的第二套若是该花色就不叫，否则叫出第二套。对**2♣2 梅花用2♦2 方块询问；对2♦2 方块用2♥2 红桃**询问高花。

2♥2 红桃后

偏好红心则不叫，偏好黑桃则叫2♠2 黑桃。

应叫例：留在已知花色

左手敌方开叫1NT1 无将，同伴争叫2♣2 梅花，右手敌方不叫：

♠ Q742黑桃: Q, 7, 4, 2.
♥ 83红心: 8, 3.
♦ K962方块: K, 9, 6, 2.
♣ J75梅花: J, 7, 5.

不叫，有三张梅花支持。第二套可能是红心，而我们只有两张。

应叫例：寻找高花

相同位置，同伴争叫2♦2 方块：

♠ Q864黑桃: Q, 8, 6, 4.
♥ K975红心: K, 9, 7, 5.
♦ 6方块: 6.
♣ J842梅花: J, 8, 4, 2.

叫2♥2 红桃，不叫或改正。两门高花都有支持，同伴持红心不叫，持黑桃叫2♠2 黑桃。

要点

  • 2♥2 红桃表示双套，不是红心单套。
  • 第二套一定比第一套级别高。
  • 寻找第二套不保证找到更好配合。
  • 同伴的2NT2 无将是带成局兴趣的询问，需要约定后续，不是简单寻找第二套。
