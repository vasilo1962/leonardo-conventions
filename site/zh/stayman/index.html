Stayman

用法、实例与应叫

1NT描述牌力与平均牌型，却没有说明是否有四张高花。Stayman在决定打无将之前寻找高花配合。

何时使用？

同伴开叫1NT，表示15–17大牌点，且对方没有争叫时，我们持至少一门四张高花和8大牌点。人为的2♣询问四张高花，不保证梅花，开叫人必须回答。同伴开叫1NT，表示15–17大牌点，且对方没有争叫时，我们持至少一门四张高花和8大牌点。人为的2梅花询问四张高花，不保证梅花，开叫人必须回答。

注：如果搭档约定直接应叫2NT是向低花的Transfer，那么无将进局邀请需经过Stayman。此时2♣不一定保证四张高花。下一课将讲低花Transfer。注：如果搭档约定直接应叫2NT是向低花的Transfer，那么无将进局邀请需经过Stayman。此时2梅花不一定保证四张高花。下一课将讲低花Transfer。

本课讲基本Stayman。弱牌用法需要合适牌型与约定的后续叫法，不在本课范围内。

有什么作用？

高花4–4配合可能比无将更好：将牌可用于将吃并发挥两手的牌型。Stayman保留选择定约花色和阶数的空间。

面对15–17大牌点，8–9大牌点通常邀请进局；10点以上通常有进局牌力。还要考虑牌型和牌张质量。

首次应叫示例

♥ Q732红心: Q, 7, 3, 2.
♦ K65方块: K, 6, 5.
♣ 92梅花: 9, 2.

我们有9大牌点。我们两门高花各有四张。叫2♣ Stayman寻找配合，然后邀请进局，尚未承诺一定进局。我们有9大牌点。我们两门高花各有四张。叫2梅花 Stayman寻找配合，然后邀请进局，尚未承诺一定进局。

♠ AQ84黑桃: A, Q, 8, 4.
♥ K732红心: K, 7, 3, 2.
♦ Q65方块: Q, 6, 5.
♣ 92梅花: 9, 2.

我们有11大牌点。我们两门高花各有四张。先叫2♣ Stayman再选择成局定约：有配合打高花，否则基本续叫是3NT。我们有11大牌点。我们两门高花各有四张。先叫2梅花 Stayman再选择成局定约：有配合打高花，否则基本续叫是3NT。

应叫人的后续叫牌

有配合时，8–9大牌点叫3♥或3♠邀请，开叫人可以不叫。10点以上且无满贯兴趣时，叫4♥或4♠止叫。有配合时，8–9大牌点叫3红桃或3黑桃邀请，开叫人可以不叫。10点以上且无满贯兴趣时，叫4红桃或4黑桃止叫。

开叫人通常最低牌力拒绝邀请、最高牌力接受。中间牌力需评估牌型、有用大牌及整体质量。

♠ Q84黑桃: Q, 8, 4.
♥ KJ73红心: K, J, 7, 3.
♦ K65方块: K, 6, 5.
♣ 972梅花: 9, 7, 2.

1NT – 2♣ – 2♥后，持9大牌点及四张红心，叫3♥邀请。由开叫人作最终决定。1 无将 – 2 梅花 – 2红桃后，持9大牌点及四张红心，叫3红桃邀请。由开叫人作最终决定。

♠ K84黑桃: K, 8, 4.
♥ AQ73红心: A, Q, 7, 3.
♦ Q65方块: Q, 6, 5.
♣ J92梅花: J, 9, 2.

持12大牌点及红心四张支持时，叫4♥止叫。即使对面是最低牌力也够进局，且无满贯兴趣。持12大牌点及红心四张支持时，叫4红桃止叫。即使对面是最低牌力也够进局，且无满贯兴趣。

没有高花配合时，8–9大牌点叫2NT邀请；10点以上且无满贯兴趣时，基本选择为3NT。

这些无将续叫假定手牌适合打无将。高花5–4牌型及特殊后续需要进一步约定，不在本课展开。

注意事项

2♣逼叫一轮，但不逼叫进局。2♦不表示方块；2♥不否认四张黑桃。基本Stayman不能只有点力。仅有一门五张或更长高花、另一门不足四张时，通常用2梅花逼叫一轮，但不逼叫进局。2方块不表示方块；2红桃不否认四张黑桃。基本Stayman不能只有点力。仅有一门五张或更长高花、另一门不足四张时，通常用Jacoby Transfer。开叫人的首次回答不说明15–17范围内的具体牌力。
