Bergen Raises

用法、实例与应叫

何时使用？

Bergen Raises用于同伴以1♥或1♠开叫、保证至少五张牌之后，应叫人须在开叫人的高花中有至少四张支持。

本课介绍应叫人此前未曾不叫、对手没有干扰的基本用法。许多搭档也约定在加倍或一阶争叫之后继续使用Bergen，前提是相关叫品仍然可用。这必须有明确的搭档约定。

有什么作用？

找到高花配合后，开叫人需要知道应叫人的牌力以及支持张数。

Bergen把至少四张支持的牌分为三类：弱牌、constructive牌和邀局牌。

双方合计至少九张将牌时，迅速叫到三阶既能压缩对手的叫牌空间，又能帮助同伴选择最终定约。在桥牌中，这把描述配合与阻击对手结合起来。

**3♣和3♦是人为叫品。**它们表示支持同伴的高花，并不保证所叫低花的长度。开叫人不得对这两个应叫不叫。

直接加叫到高花三阶则允许不叫。持很弱的牌时，要仔细考虑局况和牌型。

表中的点力范围是本课采用的约定。评估牌力时，还要考虑牌型和大牌质量。

例子

以下各例中，同伴开叫，右手对方不叫。

1. Constructive支持

**1♠**开叫后，我们持有：

♠ K842黑桃: K, 8, 4, 2.
♥ A73红心: A, 7, 3.
♦ 85方块: 8, 5.
♣ J963梅花: J, 9, 6, 3.

叫3♣。我们有8个大牌点和四张黑桃支持。此叫描述牌力与配合，不保证梅花长度。

2. 邀请成局

**1♥**开叫后，我们持有：

♠ A83黑桃: A, 8, 3.
♥ KJ74红心: K, J, 7, 4.
♦ K85方块: K, 8, 5.
♣ 963梅花: 9, 6, 3.

叫3♦。我们有11个大牌点和四张红心支持。邀请成局，让开叫人根据自己的牌决定。

3. 弱跳加叫

**1♠**开叫后，我们持有：

♠ Q974黑桃: Q, 9, 7, 4.
♥ 83红心: 8, 3.
♦ K852方块: K, 8, 5, 2.
♣ 963梅花: 9, 6, 3.

叫3♠。我们有5个大牌点和四张支持。这是阻击，不是邀局。同伴可以不叫。

4. 只有三张支持

**1♥**开叫后，我们持有：

♠ K83黑桃: K, 8, 3.
♥ Q72红心: Q, 7, 2.
♦ A854方块: A, 8, 5, 4.
♣ 963梅花: 9, 6, 3.

叫2♥。虽然有9个大牌点，但只有三张红心。Bergen 3♣会保证至少四张支持，因此不能使用。

如何继续？

开叫人现在知道双方至少有九张将牌。决定停叫还是叫局时，要综合考虑同伴已显示的牌力、自己的牌型和大牌质量。以下所有进程均假定对手一直不叫。

对**3♦**问叫，本课采用以下简单约定：

  • 应叫人持7–8点，退回3♥ /♠。
  • 持9点，叫4♥ /♠。

此问叫不保证方块。这个低限／高限划分属于本课介绍的简单版本。

**注意是谁叫3♦：**作为首次应叫，它表示10–12点的支持；作为开叫人在3♣之后的再叫，它是上述问叫。

3♦应叫之后——邀局

应叫人已经表示10–12点和至少四张支持。开叫人选择：

续叫续叫 含义含义
3♥ /♠3 红桃 /黑桃 拒绝邀局，应叫人不叫。拒绝邀局，应叫人不叫。
4♥ /♠4 红桃 /黑桃 接受邀请，叫到成局。接受邀请，叫到成局。

决定不能只看总点数。额外一张将牌、有用的短套或好的旁套，都可能增加成局机会。

直接3♥ /♠之后——弱跳加叫

持普通开叫牌时，开叫人不叫。同伴做的是阻击，并非邀局。

若要继续叫局，必须有相当多的额外打牌实力，因为同伴可能只有很少的点力。

1. 拒绝邀局

我们开叫1♥，同伴应叫3♦。手中为：

♠ K83黑桃: K, 8, 3.
♥ AQ742红心: A, Q, 7, 4, 2.
♦ K85方块: K, 8, 5.
♣ 96梅花: 9, 6.

叫3♥。我们有12个大牌点、均型牌，没有额外价值来接受邀请。同伴不叫。

2. 接受邀局

我们开叫1♥，同伴应叫3♦。手中为：

♠ A83黑桃: A, 8, 3.
♥ KQJ74红心: K, Q, J, 7, 4.
♦ AQ5方块: A, Q, 5.
♣ 96梅花: 9, 6.

叫4♥。16个大牌点、好的将牌套，加上同伴至少四张支持，足以接受邀局。

3. 以低限回答问叫

我方叫牌为1♠–3♣–3♦。作为应叫人，我们持有：

♠ K842黑桃: K, 8, 4, 2.
♥ Q73红心: Q, 7, 3.
♦ 85方块: 8, 5.
♣ Q963梅花: Q, 9, 6, 3.

叫3♠。7个大牌点是constructive应叫的低限，因此拒绝邀局。

4. 以高限回答问叫

我方叫牌为1♠–3♣–3♦。作为应叫人，我们持有：

♠ K842黑桃: K, 8, 4, 2.
♥ A73红心: A, 7, 3.
♦ 85方块: 8, 5.
♣ Q963梅花: Q, 9, 6, 3.

叫4♠。9个大牌点是constructive应叫的高限，因此接受开叫人的邀请。

注意事项

  • **Bergen要求至少四张支持。**只有三张时，按体系的其他约定处理。
  • **3♣和3♦不表示低花长度。**开叫人不得不叫。
  • 直接3♥ /♠是阻击，不是邀局。
  • **有逼局实力时，不应用3♣或3♦限制自己的牌力。**使用搭档约定的强支持，例如采用该约定时的Jacoby 2NT。
  • **不同版本的点力范围可能不同。**本课constructive 3♣为7–9点，邀局3♦为10–12点。
  • **Reverse Bergen互换3♣和3♦的含义。**必须明确采用哪个版本。
  • 加倍或一阶争叫之后，只有搭档约定继续使用且叫品仍可用时，才保留Bergen。
  • 第三或第四家开叫时，Bergen需要另外约定，尤其是使用Reverse Drury的搭档。
