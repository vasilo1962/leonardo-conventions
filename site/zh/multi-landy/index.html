Multi Landy

用法、实例与应叫

什么时候使用？

Multi Landy用于对抗敌方自然的1NT开叫。事先约定用于强无将、弱无将还是两者。本课版本中，加倍为惩罚性；2♦表示任意一门长套，也可以是低花。

有什么作用？

一次说明单套或双套牌，帮助同伴选择将牌，同时干扰敌方寻找定约。多数争叫是约定叫，不一定表示所叫的花色。

争叫要考虑牌型、套的质量、局况以及敌方1NT的实力。惩罚性加倍需要防守赢墩和合适的首攻，不能只数大牌点。

争叫实例

以下右手敌方均开叫1NT。涉及牌型的争叫，假设我方无局。

1. 双高花

♠ KQ96黑桃: K, Q, 9, 6.
♥ AJ853红心: A, J, 8, 5, 3.
♦ 7方块: 7.
♣ Q62梅花: Q, 6, 2.

叫2♣：五张红心、四张黑桃，让同伴选择高花。

2. 一门长套

♠ AQJ964黑桃: A, Q, J, 9, 6, 4.
♥ 852红心: 8, 5, 2.
♦ K72方块: K, 7, 2.
♣ 7梅花: 7.

叫**2♦**表示单套牌。不能叫2♠，因为后者还保证有一门低花。

3. 红心加低花

♠ 7黑桃: 7.
♥ KQJ86红心: K, Q, J, 8, 6.
♦ AQ974方块: A, Q, 9, 7, 4.
♣ 82梅花: 8, 2.

叫2♥，表示五张红心和一门低花。同伴尚不知道是哪门低花。

4. 黑桃加低花

♠ KJ853黑桃: K, J, 8, 5, 3.
♥ 6红心: 6.
♦ 84方块: 8, 4.
♣ AQ974梅花: A, Q, 9, 7, 4.

叫2♠，五张黑桃加低花，此处低花是梅花。

5. 双低花

♠ 7黑桃: 7.
♥ 84红心: 8, 4.
♦ KQJ96方块: K, Q, J, 9, 6.
♣ AJ874梅花: A, J, 8, 7, 4.

叫2NT，至少五张梅花和五张方块。这是约定叫，不表示平均牌型。

6. 惩罚性加倍

♠ AQJ黑桃: A, Q, J.
♥ KQ4红心: K, Q, 4.
♦ KJ93方块: K, J, 9, 3.
♣ K82梅花: K, 8, 2.

对抗弱1NT，例如12–14点，叫加倍。这手强牌有防守实力，目的是防守加倍后的1NT，而不是让同伴选花色。

同伴怎样应叫？

以下假设下一位敌方不叫。

对2♣的应叫

寻找最佳高花配合。

应叫应叫 含义含义
2♥ / 2♠2 红桃 / 2 黑桃 选择该高花，不邀局选择该高花，不邀局
2♦2 方块 两门高花等长，询问较长高花两门高花等长，询问较长高花
3♥ / 3♠3 红桃 / 3 黑桃 至少四张支持，邀局至少四张支持，邀局

有偏好的例子

♠ A842黑桃: A, 8, 4, 2.
♥ 97红心: 9, 7.
♦ J843方块: J, 8, 4, 3.
♣ 975梅花: 9, 7, 5.

应叫2♠：四张黑桃、两张红心。同伴至少四张黑桃，合计至少八张将牌。若同伴持第一个争叫例手，应当不叫，不改叫自己的五张红心。

无偏好的例子

♠ 852黑桃: 8, 5, 2.
♥ Q96红心: Q, 9, 6.
♦ A843方块: A, 8, 4, 3.
♣ 974梅花: 9, 7, 4.

应叫2♦，两门高花各三张。持第一个例手的同伴叫2♥，找到八张红心配合，而不是七张黑桃。

对2♦的应叫

还不知道长套，通常应叫2♥，属于pass or correct（不叫或改正）：持红心则不叫，否则叫出自己的长套。

  • 红心：不叫。
  • 黑桃：叫2♠。
  • 梅花：叫3♣。
  • 方块：叫3♦。

例子：用第二个争叫例手。

西西 北北 东东 南南
1NT1 无将 2♦2 方块 不叫不叫 2♥2 红桃
不叫不叫 2♠2 黑桃

南的2♥不表示红心，而是让北说明长套。也可应叫2♠，前提是同伴有红心时愿意至少打3♥；它并非自然黑桃应叫。强应叫，例如2NT询问，需要另行约定后续。

对2♥或2♠的应叫

高花已知，低花未知。

应叫应叫 含义含义
不叫不叫 选择已知高花选择已知高花
2NT2 无将 询问低花，答3♣或3♦询问低花，答3梅花或3方块
另一花色另一花色 自然叫，通常至少六张好套，准备打该花色自然叫，通常至少六张好套，准备打该花色
同伴高花的三阶加叫同伴高花的三阶加叫 本版本为邀局本版本为邀局

同伴持第三个例手争叫2♥。若不想打红心，以2NT询问，得到3♦。此处2NT不是建议打无将。

对2NT的应叫

同伴双低花至少5–5。弱牌按支持选择3♣或3♦，不能因点力少就在约定性2NT上不叫。强牌结合配合、赢墩和止张考虑成局。

对惩罚性加倍的应叫

通常不叫，防守加倍的1NT。非常弱、自己有至少五张套时，可以自然叫逃跑；不能只因点少就自动逃到四张套。

要点

  • **2♣**表示双高花。
  • **2♦**表示一门长套。
  • **2♥和2♠**还保证一门低花。
  • 2NT争叫表示双低花；应叫同伴的2♥或2♠时则询问低花。
  • Multi Landy有不同版本。必须约定加倍含义、2♦是否包含低花，以及加叫是邀局还是阻击。
