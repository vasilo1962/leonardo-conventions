Jacoby 2NT

用法、实例与应叫

何时使用？

Jacoby 2NT用于同伴开叫至少五张的1♥或1♠之后，表示至少四张支持和成局实力。本课采用第一家或第二家开叫、应叫人未曾派司且对方未干扰的情形。

有什么作用？

我们要立即显示强支持，同时保留探索满贯的叫牌空间。人工应叫2NT逼叫到局：开叫人不能派司，双方必须至少叫到成局定约。开叫人的再叫描述实力和牌型，帮助判断两手牌是否适合满贯。

2NT表示什么？

叫品叫品 含义含义
1♥ – 2NT1 红桃 – 2 无将 对开叫高花至少四张支持，并有成局实力。对开叫高花至少四张支持，并有成局实力。
1♠ – 2NT1 黑桃 – 2 无将 对开叫高花至少四张支持，并有成局实力。对开叫高花至少四张支持，并有成局实力。

同时考虑大牌点和牌型。应叫没有实力上限，也不保证平均牌型或其他花色有止张。只有三张支持时，先用其他逼叫性应叫，稍后再表示支持。

例子

1. 强红心支持

同伴开叫1♥，右手敌方派司。

♠ AQ3黑桃: A, Q, 3.
♥ KQ74红心: K, Q, 7, 4.
♦ A85方块: A, 8, 5.
♣ J96梅花: J, 9, 6.

应叫2NT Jacoby：16大牌点、四张红心。立即显示实力与支持，让同伴有空间描述牌型。平均牌型不等于必须打无将。

2. 很强的黑桃支持

同伴开叫1♠，右手敌方派司。

♠ AKJ7黑桃: A, K, J, 7.
♥ A8红心: A, 8.
♦ KQ6方块: K, Q, 6.
♣ K952梅花: K, 9, 5, 2.

应叫2NT Jacoby：20大牌点、四张黑桃。满贯很有希望，但决定最终定约前仍需更多信息。

如何继续？

下列续叫中，对方均派司。本课采用的经典版本中，开叫人这样再叫：

叫品叫品 含义含义
三阶新花色三阶新花色 该花色单张或缺门，尚未限定实力。该花色单张或缺门，尚未限定实力。
三阶原高花三阶原高花 强牌，约18点以上，无单张或缺门。强牌，约18点以上，无单张或缺门。
3NT3 无将 中等实力，约15–17点，无单张或缺门。中等实力，约15–17点，无单张或缺门。
四阶原高花四阶原高花 低限开叫，无单张或缺门。低限开叫，无单张或缺门。
四阶新花色四阶新花色 至少五张的优质第二套，可提供额外赢墩。至少五张的优质第二套，可提供额外赢墩。

点力范围仅供参考，还要考虑牌型及大牌质量。其他版本可能不同。短门使应叫人重新估值：小牌可以将吃，而短门对面的K或Q可能价值下降。直接跳叫成局是最弱的再叫；强牌保留满贯探索空间。

以下五例中，我们开叫1♠，同伴应叫2NT Jacoby。

1. 单张

♠ AQJ84黑桃: A, Q, J, 8, 4.
♥ 7红心: 7.
♦ KJ63方块: K, J, 6, 3.
♣ A85梅花: A, 8, 5.

再叫3♥，显示红心单张或缺门。这不是显示红心长度，也尚未限定实力。同伴可据此重新判断自己的牌是否有用。

2. 无短门的低限牌

♠ KQJ84黑桃: K, Q, J, 8, 4.
♥ K72红心: K, 7, 2.
♦ Q63方块: Q, 6, 3.
♣ J5梅花: J, 5.

再叫4♠。12大牌点，且无特别的牌型优势，表示低限。同伴已逼叫到局，我们只需描述低限实力。

3. 无短门的强牌

♠ AKJ84黑桃: A, K, J, 8, 4.
♥ AQ7红心: A, Q, 7.
♦ K63方块: K, 6, 3.
♣ K5梅花: K, 5.

再叫3♠。20大牌点，保留探索满贯的空间。虽然叫阶较低，却比直接叫4♠更强，而且不能派司。

4. 无短门的中等实力牌

♠ AQJ864黑桃: A, Q, J, 8, 6, 4.
♥ K7红心: K, 7.
♦ QJ3方块: Q, J, 3.
♣ K5梅花: K, 5.

再叫3NT。16大牌点，无单张或缺门，表示中等实力，并不是建议放弃已经确定的黑桃配合。

5. 优质五张第二套

♠ AKJ84黑桃: A, K, J, 8, 4.
♥ Q7红心: Q, 7.
♦ 6方块: 6.
♣ KQJ85梅花: K, Q, J, 8, 5.

再叫4♣，显示可提供额外赢墩的优质五张第二套。本版本优先显示这种好套，而不是单张，所以叫4♣而不叫3♦。这不只是显示梅花控制。

应叫人如何继续？

根据开叫人的描述重新估值。没有满贯意图时，叫四阶已配合的高花；若开叫人已直接成局表示低限，则可派司。很强的应叫人即使面对低限也可继续，因为Jacoby没有实力上限。

有满贯意图时，用控制叫继续：按双方约定显示A、K、单张或缺门。将牌已经确定，叫新花色不是寻找另一种配合。

有足够信息判断满贯后，再问A或关键张。不要只因点多就自动叫4NT；应先评估控制、将牌质量和两手牌的配合。

短门后的重新估值

两例均为：同伴开叫1♠，我们应叫2NT Jacoby，同伴再叫3♥，表示红心单张或缺门。

1. 大牌在短门之外

♠ AQ74黑桃: A, Q, 7, 4.
♥ 864红心: 8, 6, 4.
♦ KQ5方块: K, Q, 5.
♣ A83梅花: A, 8, 3.

红心短门使本手增值：三张小红心可将吃，大牌则位于其他花色。叫4♣，显示梅花控制和满贯意图，既不保证梅花长度，也尚未确定最终定约。

2. 大牌集中在短门对面

♠ QJ74黑桃: Q, J, 7, 4.
♥ KQJ红心: K, Q, J.
♦ K85方块: K, 8, 5.
♣ J63梅花: J, 6, 3.

叫4♠。虽然有成局实力，但不少大牌点在同伴短门对面的红心，其他花色的实力有限。依据现有信息，不鼓励继续探索满贯。

注意事项

Jacoby 2NT与Bergen Raises相互补充。本版本中，持至少四张将牌时，Bergen处理弱牌、建设性加叫和邀叫，Jacoby则处理成局实力或更强的牌。

不要把Jacoby 2NT与Jacoby转移叫混淆：此处2NT是对1♥或1♠的应叫，表示强支持。

本版本不用于已派司的应叫人，也不用于对方加倍或争叫之后。2NT之后对方的干扰不取消逼叫到局，但后续处理须另作约定。

使用前尤其要约定3NT和四阶新花色的含义，不同版本并不相同。
