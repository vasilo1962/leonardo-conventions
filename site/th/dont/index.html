เรียนบริดจ์

DONT

การใช้ ตัวอย่าง และคำตอบ

ใช้เมื่อใด?

เหนือการเปิด 1NT แข็ง ของฝ่ายตรงข้าม ทั้งตำแหน่งถัดจากผู้เปิดทันที และตำแหน่งที่สี่หลังจาก Pass สองครั้ง

มีจุดประสงค์อะไร?

บอกมือยาวสีเดียวหรือสองสี โดยมากอยู่ระดับสอง เพื่อหาสัญญาฝ่ายเราและรบกวนคู่แข่ง Double ไม่ใช่ลงโทษ แต่แสดงมือยาวสีเดียว

แต่ละคำประมูลหมายถึงอะไร?

หลัง 1NT ความหมาย
Double ยาวสีเดียว ยังไม่ระบุสี
2♣ ดอกจิกกับสีที่สูงกว่า: ข้าวหลามตัด โพแดง หรือโพดำ
2♦ ข้าวหลามตัดกับเมเจอร์
2♥ โพแดงกับโพดำ
2♠ โพดำตามธรรมชาติ

มือสองสีต้องอย่างน้อย 5–4 สีต่ำกว่าไม่จำเป็นต้องเป็นห้าใบ ตัวอย่างมือสีเดียวใช้ หกใบขึ้นไป

แทรกได้แม้แต้มไพ่ใหญ่ไม่มาก หากการกระจายและคุณภาพสีเหมาะสม การอยู่ระดับสองได้ช่วยให้แทรกเชิงรุก โดยเฉพาะตำแหน่งที่สี่ ต้องพิจารณา vulnerability ซึ่งกระทบโบนัสและค่าปรับด้วย

คู่ตอบอย่างไร?

การเดินต่อสมมติว่าฝ่ายตรงข้าม Pass

หลัง Double

ปกติตอบ 2♣ ให้คู่บอกสี:

ผู้ Double เดินต่อ สี
Pass ดอกจิก
2♦ ข้าวหลามตัด
2♥ โพแดง
2♠ โพดำ

2♣ ไม่รับรองดอกจิก อย่าปล่อย Double ไว้ราวกับเป็นการลงโทษ

หลัง 2♣ หรือ 2♦

Pass ได้ถ้าสีที่รู้เหมาะสม มิฉะนั้นเรียกสีถัดไปเป็น pass or correct ให้คู่ Pass ถ้านั่นคือสีที่สอง หรือแก้เป็นสีจริง หลัง 2♣ ใช้ 2♦ ถามสีที่สอง หลัง 2♦ ใช้ 2♥ ถามเมเจอร์

หลัง 2♥

เลือกโพแดงให้ Pass เลือกโพดำให้เรียก 2♠

ตัวอย่างคำตอบ: อยู่ในสีที่รู้

ฝ่ายตรงข้ามซ้ายเปิด 1NT คู่เรียก 2♣ ฝ่ายตรงข้ามขวา Pass:

♠ Q742โพดำ: ควีน, 7, 4, 2.
♥ 83โพแดง: 8, 3.
♦ K962ข้าวหลามตัด: คิง, 9, 6, 2.

Pass เพราะมีดอกจิกสนับสนุนสามใบ สีที่สองอาจเป็นโพแดงซึ่งเรามีแค่สอง

ตัวอย่างคำตอบ: หาเมเจอร์

ตำแหน่งเดียวกัน คู่เรียก 2♦:

♠ Q864โพดำ: ควีน, 8, 6, 4.
♥ K975โพแดง: คิง, 9, 7, 5.
♦ 6ข้าวหลามตัด: 6.
♣ J842ดอกจิก: แจ็ก, 8, 4, 2.

เรียก 2♥ แบบ pass or correct เราสนับสนุนได้ทั้งสองเมเจอร์ คู่ Pass ด้วยโพแดง หรือเรียก 2♠ ด้วยโพดำ

ข้อควรจำ

  • 2♥ แสดงสองสี ไม่ใช่โพแดงสีเดียว
  • สีที่สองมีอันดับสูงกว่าสีแรกเสมอ
  • การหาสีที่สองไม่รับประกันฟิตที่ดีกว่า
  • 2NT ของคู่ เป็นคำถามพร้อมความสนใจเกม ต้องตกลงการเดินต่อ ไม่ใช่คำถามธรรมดาเพื่อหาสีที่สอง
