# Multi Landy

## いつ使う？

相手のナチュラルな**1NTオープン**に対するディフェンスです。強い1NT、弱い1NT、または両方に使うかを事前に決めます。ここでは**ダブルはペナルティ**、**2♦は任意の１スートの長い手**で、マイナーも含みます。

## 目的は？

１スーターや２スーターを示し、パートナーが切札を選びやすくするとともに、相手のビディングを妨げます。多くのオーバーコールは人工的で、実際にそのスートを持つとは限りません。

## 各オーバーコールの意味は？

| コール | 意味 |
| --- | --- |
| ダブル | ペナルティ。1NTを落とせると判断 |
| 2♣ | 両メジャー、少なくとも5–4 |
| 2♦ | 任意の６枚以上の１スート。通常はメジャー |
| 2♥ | ハート５枚とマイナー。マイナーは通常５枚だが、良い４枚でも可 |
| 2♠ | スペード５枚とマイナー。マイナーは通常５枚だが、良い４枚でも可 |
| 2NT | 両マイナー、少なくとも5–5 |
| 3♣ / 3♦ | そのマイナーのナチュラルなオーバーコール |

判断には分布、スートの質、バルネラビリティ、相手の1NTの強さを考慮します。ペナルティ・ダブルには守備のトリックと適切なオープニングリードが必要で、点数だけでは決めません。

## オーバーコールの例

以下は右の相手が1NTでオープン。分布を示すオーバーコールでは自分たちはノンバルとします。

### 1. 両メジャー

♠ KQ96  
♥ AJ853  
♦ 7  
♣ Q62

**2♣**。ハート５枚、スペード４枚を示し、選択をパートナーに任せます。

### 2. 長い１スート

♠ AQJ964  
♥ 852  
♦ K72  
♣ 7

**2♦**で１スーターを示します。2♠ではありません。2♠はマイナーも約束するからです。

### 3. ハートとマイナー

♠ 7  
♥ KQJ86  
♦ AQ974  
♣ 82

**2♥**。ハート５枚とマイナーを示します。どちらのマイナーかはまだ不明です。

### 4. スペードとマイナー

♠ KJ853  
♥ 6  
♦ 84  
♣ AQ974

**2♠**。スペード５枚とマイナー。この手ではクラブです。

### 5. 両マイナー

♠ 7  
♥ 84  
♦ KQJ96  
♣ AJ874

**2NT**でクラブとダイヤモンドを各５枚以上示します。人工的なビッドで、バランスハンドではありません。

### 6. ペナルティ・ダブル

♠ AQJ  
♥ KQ4  
♦ KJ93  
♣ K82

例えば12–14点の弱い1NTに**ダブル**。守備力のある強い手なので、1NTダブルを守りたいのであり、スート選択を求めていません。

## どうレスポンスする？

次の相手がパスした場合です。

### 2♣の後

最適なメジャーフィットを探します。

| レスポンス | 意味 |
| --- | --- |
| 2♥ / 2♠ | そのメジャーへの選好。ゲームへのインビテーションではない |
| 2♦ | 両メジャー同じ枚数。長い方を尋ねる |
| 3♥ / 3♠ | ４枚以上のサポート、ゲームへのインビテーション |

**選好がある例**

♠ A842  
♥ 97  
♦ J843  
♣ 975

**2♠**。スペード４枚、ハート２枚。パートナーに最低４枚あるので計８枚以上です。最初のオーバーコール例の手ならパートナーはパスし、自分の５枚ハートへ直しません。

**選好がない例**

♠ 852  
♥ Q96  
♦ A843  
♣ 974

両メジャー３枚ずつで**2♦**。最初の例の手ならパートナーは**2♥**。スペード７枚でなくハート８枚のフィットを見つけます。

### 2♦の後

長いスートは未確定。通常は**2♥**を**pass or correct（そのスートならパス、それ以外なら訂正）**として使います。

- ハートならパス。
- スペードなら2♠。
- クラブなら3♣。
- ダイヤモンドなら3♦。

**例**：２番目のオーバーコールの手。

| 西 | 北 | 東 | 南 |
| --- | --- | --- | --- |
| 1NT | 2♦ | パス | 2♥ |
| パス | **2♠** | | |

南の2♥はハートを示さず、北の長いスートを明らかにします。**2♠**で答えることもできますが、パートナーがハートなら少なくとも3♥でプレーする用意が必要です。これはナチュラルなスペードではありません。2NTの質問など強いレスポンスには、その後の追加の取り決めが必要です。

### 2♥または2♠の後

メジャーは既知、マイナーは不明です。

| レスポンス | 意味 |
| --- | --- |
| パス | 既知のメジャーでプレー |
| 2NT | マイナーを尋ねる。答えは3♣または3♦ |
| 別のスート | ナチュラル。通常良い６枚以上、そのスートでプレー |
| パートナーのメジャーを３にレイズ | この版ではゲームへのインビテーション |

パートナーが３番目の手で**2♥**。ハートを避けたければ**2NT**で尋ね、**3♦**を聞きます。ここで2NTはノートランプでのプレーを提案しません。

### 2NTの後

両マイナー最低5–5です。弱い手ならサポートに従って**3♣か3♦**を選び、点が少ないからと人工的な2NTをパスしません。強い手ではフィット、トリック、ストッパーを考えてゲームを検討します。

### ペナルティ・ダブルの後

通常は**パス**して守ります。非常に弱く自分に５枚以上のスートがあれば、ナチュラルな逃げのビッドも可能です。単に弱いという理由だけで４枚スートに逃げません。

## 注意点

- **2♣**は両メジャー。
- **2♦**は長い１スート。
- **2♥と2♠**はマイナーも約束。
- **2NT**のオーバーコールは両マイナー。2♥や2♠へのレスポンスならマイナーへの質問。
- 版によって違います。ダブル、2♦にマイナーを含むか、レイズがインビテーションかプリエンプトかを合意します。
