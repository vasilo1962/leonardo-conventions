# Multi Landy

## ใช้เมื่อใด?

เป็นข้อตกลงป้องกันการเปิด **1NT แบบธรรมชาติ** ของฝ่ายตรงข้าม ต้องตกลงกับคู่ก่อนว่าใช้กับ 1NT แบบแข็ง แบบอ่อน หรือทั้งสองแบบ ในบทนี้ **Double เป็นการลงโทษ** ส่วน **2♦ แสดงไพ่ยาวสีเดียว** ซึ่งอาจเป็นสีใดก็ได้ทั้งสี่สี

## มีจุดประสงค์อะไร?

บอกไพ่ยาวหนึ่งหรือสองสี ช่วยคู่เลือกทรัมป์และรบกวนการหาสัญญาของฝ่ายตรงข้าม การแทรกประมูลหรือ overcall ส่วนใหญ่เป็นข้อตกลง ไม่จำเป็นต้องมีสีที่เรียก เมเจอร์คือ ♥ และ ♠ ส่วนไมเนอร์คือ ♣ และ ♦

## แต่ละคำประมูลหมายถึงอะไร?

| การแทรก | ความหมาย |
| --- | --- |
| Double | ลงโทษ เชื่อว่าสามารถทำให้ 1NT ล้มเหลวได้ |
| 2♣ | สองเมเจอร์ อย่างน้อย 5–4 |
| 2♦ | สีใดสีหนึ่งอย่างน้อยหกใบ โดยมากเป็นเมเจอร์ |
| 2♥ | โพแดงห้าใบกับไมเนอร์ โดยมากไมเนอร์ห้าใบ แต่สี่ใบที่ดีก็ใช้ได้ |
| 2♠ | โพดำห้าใบกับไมเนอร์ โดยมากไมเนอร์ห้าใบ แต่สี่ใบที่ดีก็ใช้ได้ |
| 2NT | สองไมเนอร์ อย่างน้อย 5–5 |
| 3♣ / 3♦ | แทรกตามธรรมชาติในไมเนอร์นั้น |

พิจารณาการกระจายไพ่ คุณภาพสี ภาวะ vulnerability ซึ่งมีผลต่อโบนัสและค่าปรับ และความแข็งของ 1NT ฝ่ายตรงข้าม การ Double เพื่อลงโทษต้องมีทริกป้องกันและไพ่เริ่มนำที่เหมาะสม ไม่ใช่นับแต้มเพียงอย่างเดียว

## ตัวอย่างการแทรก

ทุกตัวอย่างฝ่ายตรงข้ามทางขวาเปิด 1NT สำหรับการแทรกด้วยรูปไพ่ สมมติว่าฝ่ายเราเป็น non-vulnerable

### 1. สองเมเจอร์

♠ KQ96  
♥ AJ853  
♦ 7  
♣ Q62

เรียก **2♣** แสดงโพแดงห้าใบ โพดำสี่ใบ ให้คู่เลือก

### 2. ไพ่ยาวสีเดียว

♠ AQJ964  
♥ 852  
♦ K72  
♣ 7

เรียก **2♦** ไม่ใช่ 2♠ เพราะ 2♠ ยังรับรองว่ามีไมเนอร์ด้วย

### 3. โพแดงกับไมเนอร์

♠ 7  
♥ KQJ86  
♦ AQ974  
♣ 82

เรียก **2♥** แสดงโพแดงห้าใบกับไมเนอร์ คู่ยังไม่ทราบว่าไมเนอร์ใด

### 4. โพดำกับไมเนอร์

♠ KJ853  
♥ 6  
♦ 84  
♣ AQ974

เรียก **2♠** แสดงโพดำห้าใบกับไมเนอร์ ซึ่งในมือนี้คือดอกจิก

### 5. สองไมเนอร์

♠ 7  
♥ 84  
♦ KQJ96  
♣ AJ874

เรียก **2NT** แสดงดอกจิกและข้าวหลามตัดอย่างน้อยสีละห้าใบ เป็นคำประมูลตามข้อตกลง ไม่ใช่มือสมดุล

### 6. Double เพื่อลงโทษ

♠ AQJ  
♥ KQ4  
♦ KJ93  
♣ K82

เมื่อเจอ 1NT อ่อน เช่น 12–14 แต้ม เรียก **Double** มือนี้แข็งและมีค่าป้องกัน เราต้องการป้องกัน 1NT ที่ถูก Double ไม่ได้ขอให้คู่เลือกสี

## คู่ตอบอย่างไร?

คำตอบต่อไปนี้ใช้เมื่อฝ่ายตรงข้ามคนถัดไป Pass

### หลัง 2♣

มองหาฟิตเมเจอร์ที่ดีที่สุด

| คำตอบ | ความหมาย |
| --- | --- |
| 2♥ / 2♠ | เลือกเมเจอร์นั้น ไม่ได้เชิญเกม |
| 2♦ | เมเจอร์ยาวเท่ากัน ถามสีที่ยาวกว่า |
| 3♥ / 3♠ | สนับสนุนอย่างน้อยสี่ใบและเชิญเกม |

**ตัวอย่างที่มีสีชอบ**

♠ A842  
♥ 97  
♦ J843  
♣ 975

ตอบ **2♠** เพราะมีโพดำสี่และโพแดงสอง คู่มีโพดำอย่างน้อยสี่ จึงรวมกันอย่างน้อยแปดทรัมป์ ถ้าคู่ถือมือแทรกตัวอย่างแรกให้ Pass ไม่แก้ไปยังโพแดงห้าใบของตน

**ตัวอย่างที่ไม่ชอบสีใดเป็นพิเศษ**

♠ 852  
♥ Q96  
♦ A843  
♣ 974

ตอบ **2♦** เพราะเมเจอร์มีสีละสามใบ คู่ที่ถือมือแรกตอบ **2♥** พบโพแดงรวมแปดใบแทนโพดำเจ็ดใบ

### หลัง 2♦

ยังไม่รู้สียาวของคู่ ปกติตอบ **2♥** แบบ **pass or correct** คือให้ Pass ถ้ามีโพแดง มิฉะนั้นแก้เป็นสียาวของตน

- โพแดง: Pass
- โพดำ: 2♠
- ดอกจิก: 3♣
- ข้าวหลามตัด: 3♦

**ตัวอย่าง** โดยใช้มือแทรกที่สอง:

| ตะวันตก | เหนือ | ตะวันออก | ใต้ |
| --- | --- | --- | --- |
| 1NT | 2♦ | Pass | 2♥ |
| Pass | **2♠** | | |

2♥ ของใต้ไม่ได้แสดงโพแดง แต่เปิดทางให้เหนือบอกสียาว ตอบ **2♠** ได้ด้วยหากพร้อมเล่นอย่างน้อย 3♥ เมื่อคู่มีโพแดง ไม่ใช่โพดำตามธรรมชาติ คำตอบแข็ง เช่นคำถาม 2NT ต้องตกลงการเดินต่อเพิ่มเติม

### หลัง 2♥ หรือ 2♠

รู้เมเจอร์แต่ยังไม่รู้ไมเนอร์

| คำตอบ | ความหมาย |
| --- | --- |
| Pass | เล่นเมเจอร์ที่รู้ |
| 2NT | ถามไมเนอร์ ตอบ 3♣ หรือ 3♦ |
| สีอื่น | ธรรมชาติ โดยมากอย่างน้อยหกใบที่ดี เพื่อเล่นสีนั้น |
| ยกเมเจอร์คู่ถึง 3 | ในแบบของเราเป็นการเชิญเกม |

คู่แทรก **2♥** ด้วยมือที่สาม ถ้าไม่ต้องการเล่นโพแดง ให้ถาม **2NT** คู่ตอบ **3♦** ที่นี่ 2NT ไม่ได้เสนอเล่นโนทรัมป์

### หลัง 2NT

คู่มีไมเนอร์อย่างน้อย 5–5 มืออ่อนเลือก **3♣ หรือ 3♦** ตามไพ่สนับสนุน ไม่ Pass บน 2NT ตามข้อตกลงเพียงเพราะแต้มน้อย มือแข็งพิจารณาเกมจากฟิต จำนวนทริก และไพ่หยุดสีฝ่ายตรงข้าม

### หลัง Double ลงโทษ

ปกติ **Pass** แล้วป้องกัน ถ้าอ่อนมากและมีสีของตนอย่างน้อยห้าใบ อาจหนีด้วยการประมูลธรรมชาติ อย่าหนีไปสีสี่ใบโดยอัตโนมัติเพียงเพราะแต้มน้อย

## ข้อควรจำ

- **2♣** แสดงสองเมเจอร์
- **2♦** แสดงสียาวสีเดียว
- **2♥ และ 2♠** รับรองไมเนอร์ด้วย
- **2NT** ที่แทรกแสดงสองไมเนอร์ แต่ถ้าตอบ 2♥ หรือ 2♠ จะถามไมเนอร์
- Multi Landy มีหลายแบบ ต้องตกลงความหมาย Double การรวมไมเนอร์ใน 2♦ และการยกสีว่าเชิญเกมหรือรบกวน
