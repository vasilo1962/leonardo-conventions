# Multi Landy

## 什么时候使用？

Multi Landy用于对抗敌方自然的**1NT开叫**。事先约定用于强无将、弱无将还是两者。本课版本中，**加倍为惩罚性**；**2♦表示任意一门长套**，也可以是低花。

## 有什么作用？

一次说明单套或双套牌，帮助同伴选择将牌，同时干扰敌方寻找定约。多数争叫是约定叫，不一定表示所叫的花色。

## 各争叫表示什么？

| 争叫 | 含义 |
| --- | --- |
| 加倍 | 惩罚性，认为能够击败1NT |
| 2♣ | 双高花，至少5–4 |
| 2♦ | 任意一门至少六张的长套，通常是高花 |
| 2♥ | 五张红心加一门低花，低花通常五张，也可为好的四张套 |
| 2♠ | 五张黑桃加一门低花，低花通常五张，也可为好的四张套 |
| 2NT | 双低花，至少5–5 |
| 3♣ / 3♦ | 相应低花的自然争叫 |

争叫要考虑牌型、套的质量、局况以及敌方1NT的实力。惩罚性加倍需要防守赢墩和合适的首攻，不能只数大牌点。

## 争叫实例

以下右手敌方均开叫1NT。涉及牌型的争叫，假设我方无局。

### 1. 双高花

♠ KQ96  
♥ AJ853  
♦ 7  
♣ Q62

叫**2♣**：五张红心、四张黑桃，让同伴选择高花。

### 2. 一门长套

♠ AQJ964  
♥ 852  
♦ K72  
♣ 7

叫**2♦**表示单套牌。不能叫2♠，因为后者还保证有一门低花。

### 3. 红心加低花

♠ 7  
♥ KQJ86  
♦ AQ974  
♣ 82

叫**2♥**，表示五张红心和一门低花。同伴尚不知道是哪门低花。

### 4. 黑桃加低花

♠ KJ853  
♥ 6  
♦ 84  
♣ AQ974

叫**2♠**，五张黑桃加低花，此处低花是梅花。

### 5. 双低花

♠ 7  
♥ 84  
♦ KQJ96  
♣ AJ874

叫**2NT**，至少五张梅花和五张方块。这是约定叫，不表示平均牌型。

### 6. 惩罚性加倍

♠ AQJ  
♥ KQ4  
♦ KJ93  
♣ K82

对抗弱1NT，例如12–14点，叫**加倍**。这手强牌有防守实力，目的是防守加倍后的1NT，而不是让同伴选花色。

## 同伴怎样应叫？

以下假设下一位敌方不叫。

### 对2♣的应叫

寻找最佳高花配合。

| 应叫 | 含义 |
| --- | --- |
| 2♥ / 2♠ | 选择该高花，不邀局 |
| 2♦ | 两门高花等长，询问较长高花 |
| 3♥ / 3♠ | 至少四张支持，邀局 |

**有偏好的例子**

♠ A842  
♥ 97  
♦ J843  
♣ 975

应叫**2♠**：四张黑桃、两张红心。同伴至少四张黑桃，合计至少八张将牌。若同伴持第一个争叫例手，应当不叫，不改叫自己的五张红心。

**无偏好的例子**

♠ 852  
♥ Q96  
♦ A843  
♣ 974

应叫**2♦**，两门高花各三张。持第一个例手的同伴叫**2♥**，找到八张红心配合，而不是七张黑桃。

### 对2♦的应叫

还不知道长套，通常应叫**2♥**，属于**pass or correct（不叫或改正）**：持红心则不叫，否则叫出自己的长套。

- 红心：不叫。
- 黑桃：叫2♠。
- 梅花：叫3♣。
- 方块：叫3♦。

**例子**：用第二个争叫例手。

| 西 | 北 | 东 | 南 |
| --- | --- | --- | --- |
| 1NT | 2♦ | 不叫 | 2♥ |
| 不叫 | **2♠** | | |

南的2♥不表示红心，而是让北说明长套。也可应叫**2♠**，前提是同伴有红心时愿意至少打3♥；它并非自然黑桃应叫。强应叫，例如2NT询问，需要另行约定后续。

### 对2♥或2♠的应叫

高花已知，低花未知。

| 应叫 | 含义 |
| --- | --- |
| 不叫 | 选择已知高花 |
| 2NT | 询问低花，答3♣或3♦ |
| 另一花色 | 自然叫，通常至少六张好套，准备打该花色 |
| 同伴高花的三阶加叫 | 本版本为邀局 |

同伴持第三个例手争叫**2♥**。若不想打红心，以**2NT**询问，得到**3♦**。此处2NT不是建议打无将。

### 对2NT的应叫

同伴双低花至少5–5。弱牌按支持选择**3♣或3♦**，不能因点力少就在约定性2NT上不叫。强牌结合配合、赢墩和止张考虑成局。

### 对惩罚性加倍的应叫

通常**不叫**，防守加倍的1NT。非常弱、自己有至少五张套时，可以自然叫逃跑；不能只因点少就自动逃到四张套。

## 要点

- **2♣**表示双高花。
- **2♦**表示一门长套。
- **2♥和2♠**还保证一门低花。
- **2NT**争叫表示双低花；应叫同伴的2♥或2♠时则询问低花。
- Multi Landy有不同版本。必须约定加倍含义、2♦是否包含低花，以及加叫是邀局还是阻击。
